# 移植设计

目的：微信里访问同一 Stats 记录与历史档案，减少两份设计的维护成本。

## 当前移动端设计作为唯一来源

2026-10-01 用户明确 Stats 移动端正在翻新。以工作区中的新版移动端页面为设计来源，页面顺序、导航、标题、卡片、筛选和数据呈现均跟随 Stats；不在小程序另行设计第二套页面。R7/R8 接入页头、赛事上下文、底栏、周赛、完整历史首页和比赛详情。2026-10-02 R9 将其余已接入公开页的控制器与组件依赖闭包统一为构建时读取当前 JSX/CSS，覆盖目录、排行榜、队伍/选手的档案/征程/分析、图谱、工作人员、回顾、晋级和匿名关注空间；DataLayout 的纯路由布局判定保留原来源。登录、参赛与私有报告尚未接入，不能因此称为所有 Stats 功能已完成。

来源对应：`PublicHeader` / `PublicMobileNav` / `EventContextBar` → 页头、底栏与赛事上下文；`DataLayout` 与 `fd-design/layoutStyles.js` / `FdDesignTokens.css` → 各页移动层级与通用布局；周赛、参赛阵容、队伍/选手、排行榜、图谱、回顾组件 → 各公开功能的实际移动页面；`MySpacePage` 与账号/周赛房间组件 → 后续账号和参赛页面。已生成的底栏图标、CSS 和各语言短标签直接读取当前 Stats 源码。

兼容的纯组件与样式共用或在构建时转换；浏览器路由、DOM 弹窗、表格、横向滚动、存储、登录会话和 Canvas 使用平台适配。`canonical-public-sources.mjs` 选择当前 KPR 分支并收集 JSX/UI hook/CSS 闭包；`prepare-mobile-design.mjs` 保留源声明，只替换平台 API 与不支持的标签/选择器。横向容器保留原作者的内层 grid/flex，由外层微信 ScrollView 负责滚动；原 SVG 路径和图表数据由 Canvas 绘制。FC 账号入口使用原纯头像/按钮样式，当前只说明登录尚未接入。源码和模型记录来源哈希，原版改动后重建同步；同条件截图与原生/安卓交互分别验收。旧快照实现不作为新版设计验收依据。保持根 Stats 的正在进行的改动，仅在试验层接入来源。

## 剩余主要开发轮次

预计 4 个主要交付轮次，每轮以可操作版本及相应验证为完成条件，不等同于四条聊天消息。轮数取决于新版设计完成度、账号接口适配和真机结果；发现新差异时补修，备案/认证/送审等待不计入开发轮次。

1. 新版移动设计对齐及公开功能收尾：统一各公开页面、回顾播放视觉、阵容/展览/签名导出；验证 R5/R6 新增功能。
2. 账号与我的：复用 System 身份、会话和赛季权限，接账号空间、云端关注、任务与通信、专属报告；验证未登录、无权限、切换账号/赛事和会话过期。
3. 参赛操作：报名/激活、阵容、比赛房间、准备/选图/赛果、预测等；在隔离测试数据上验证权限、重复操作、失败与重连，不操作生产赛事来做测试。
4. 完整原生联调和安卓验收：贯通公开查询、登录、参赛、分享与保存，核对设计、冷启动、网络中断、返回栈及包体；整理可交付预览，正式上传/送审另行记录。

视觉沿用用户确认的 FC Signal 编辑式赛事设计：纸色 #eeede6、墨色 #181a17、信号黄 #f4c320；标题 Barlow Condensed Black，中文 PingFang SC / Microsoft YaHei。使用 Stats 标题、分隔线、紧凑数据行与五项底栏。已有品牌覆盖技能默认字体/布局规则，不另建主题。

公开目录生成自 `src/config/seasons.js` 的 SEASONS 字面量，不执行 Web 环境开关或引入私人试用目录。纯模型直接导入；Web-only 季节/语言存储在构建边界替换。请求固定为已授权的 System 公开接口。

切换赛事新建根页，详情带 season，返回只复用同赛事根页。关注每赛事独立，旧 FCW26 存储兼容。检查快照实际赛事，取消过期更新，禁止跨赛事缓存降级。

周赛保留 RR5 组件；历史赛事复用原晋级、排名、阵容、评分、地图、英雄、回顾模型。平台不支持的 HTML 表格改用原生兼容标签和共享样式。图表、海报与登录分别适配。

四语言偏好沿用 Stats 原键与 locale 契约。原字典优先，原生新文案补充；繁体仅转换界面/故事文本，保护队伍、选手、工作人员名字和 BattleTag。链接显式携带语言，本机语言设置失败时仍保留当前选择。

经典经理在独立分包复用原页面与引擎，仅替换路由、存储、弹窗和滚动边界。存档按赛事隔离，写入失败不继续扣币/推进；测试后恢复原存档。它是本机模拟，不与真实赛事写操作混用。

高级海报在独立分包由构建脚本提取原纯载荷和 Canvas 绘图代码，仅替换 Canvas/Image/PNG/二维码/Path2D 边界。原 SVG 徽记在构建时栅格化；缺少原生 filter 时使用有序像素滤镜。原版字体不能依赖 DOM FontFace，使用本机回退。画布取得、图片读取和整个生成过程分别有截止时间，组件离开后忽略迟到结果。观众署名只存在当前页面/图片，不出现在分享或诊断数据中。

验证真实/稀疏快照模型、请求与关注隔离、详情返回、分享；原生点击、状态、截图、实际 PNG 和 QR；由用户安卓手机最终验收。主包及分包在生成全部资源后检查大小，使用 UTF-8 输出，防止中文/韩文转义导致超限。所有来源哈希与编译包分别留存。
