# 微信账号与参赛候选 C1

当前原生标识：wechat-native-20261027-c1。

本候选从公开原生版 b074ea0f9267ff9e45788b77d8cf49753afd798d 继续开发；该公开版来源于已接受的 Stats UI 36a26a9e4fb4ff6552eee43b35c50d7b9a49ecbb。
System 配套基线为 ccd94840d46afd12a60a97d97a267119154245d9。

## 本轮范围

- 公开页增加“我的”入口，原有四个公开底部入口和匿名关注继续可用。
- 独立账号分包处理微信登录、关联原账号、恢复、退出、队伍/待办及每周确认、名单草稿和提交。
- 网页账号设置增加“微信关联”，可核对状态并用当前密码解绑。
- 原生账号使用 /api/mini/v1 专用 Bearer。原网页 Cookie 请求层继续独立。
- 绑定票据和密码仅存在于当前操作内存；持久化仅含短期凭证、到期时间和最小账号信息。退出、失效、切号和模式变化会清空私有缓存，迟到响应不能恢复旧账号。
- 私有缓存只存内存，按环境、账号、模式、赛事和接口分隔，最长复用 30 秒，且不能超出会话寿命。
- 参赛提交携带原 revision；请求超时、断网或冲突后需重新读取状态，不自动重放写入。草稿同步名单与可赛时间，避免丢弃另一部分编辑。
- 私有账号页禁用微信分享；不把票据、凭证、账号或私有待办放进公开分享路径。

## 明确标注的本机界面预览

    npm run build:account-visual
    npm run serve:account-visual

地址为 http://127.0.0.1:3041/#/account/pages/index。页面始终标注“本机模拟预览 · 账号与赛事均为虚构”。
虚构账号为 demo@example.test，虚构密码为 NativeDemo123!。输入“模拟断网”作为可赛说明，可验证提交已保存但响应不确定时的刷新恢复。

预览只用于表单和布局验收，账号请求由构建时替换的内存夹具处理。它只允许 H5 专用构建，输出到独立的 dist/h5-account-visual。
默认原生输出不导入该夹具；包检查会拒绝虚构凭证和服务端微信交换代码。原生正式构建不能使用这份 H5 输出。

## 真实联调前的待确认项

小程序后台的当前服务类目，以及 AppSecret 是否已安全保存并可配置到 System 服务端。不要将密钥正文发到聊天中。
两个服务端开关默认关闭；先验证登录，再验证参赛提交，最后接完整比赛房。
