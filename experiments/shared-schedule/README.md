# Stats 原生小程序迁移

**当前开发入口见 [2026-10-27 原生候选说明](NATIVE-EDITION-20261027.md)。** 本轮从当前已上线 Stats 设计重新生成，构建标记为 `public-native-20261027-r5`；下面保留旧实验历史，不代表本轮已上传或获得手机验收。旧经典经理及海报画布分包已从本轮页面注册表移除。

## 旧实验历史

当前构建 `public-native-r10-20261003`，先完善公开查询与历史赛事，再接账号与参赛操作。R9 将已接入公开页面统一到当前 Stats 移动端源码；R10 修正固定尺寸、继承文字、重复缓存通知、路由布局状态和原生文字节点转换，保留同一设计来源。R4 四赛事查询已获用户安卓验收，R9 续码后已获用户手机“显示正常”反馈；R10 手机视觉与交互验收待完成。完整功能对照见 [PARITY.md](PARITY.md)，实际验证见 [VERIFICATION.md](VERIFICATION.md)，后续移动设计打磨见 [mobile-polish.md](specs/stats-parity/mobile-polish.md)。

支持 FCW26 周赛、FCR26 常规赛、QGCS4 合作赛事、FCA26 学院赛。公开赛事目录生成自 Stats 的 SEASONS 字面量，读取对应 System 公开快照；周赛保留官方 RR5 与周期积分。历史总览、赛程筛选、逐图数据、晋级与名次、参赛阵容、选手/队伍/工作人员档案、技术分析、排行榜、地图/英雄档案、故事回顾和本机关注已接入原生页面。

筛选保存在同赛事根页，详情返回继续原查询。赛事切换隔离缓存与关注；分享仅包含公开赛事、身份、地图及有效章节，不带搜索、关注或账号信息。账号、参赛操作、云端关注和专属报告仍属于后续阶段。已接入 Stats 的简体、繁体、英文、韩文语言契约和故事文案，保留公开名字与 BattleTag。

回顾中「纪念票与海报」打开独立原生画布页面，复用原版票面、电影海报、电影票和导演版绘图逻辑，支持经典/现代票面、英雄选择和人物位置设置。图片与字体、文件保存使用微信适配；字体回退及 SVG 栅格化不等于 Web 逐像素复刻。原电影播放视觉、展览/阵容/签名图片导出仍待迁移。

经典经理复用原 Fantasy/Shop/Battle/Champion/Career 和引擎，模拟与进度保存在按赛事隔离的本机存档。它不写真实赛事数据；尚未得到 R5/R6 的手机专项验收。本轮重点是公开目录、人物与队伍档案、排行榜、图谱、回顾、晋级和本机关注的完整设计来源接入。

## 微信开发

在本目录执行 `npm test`、`npm run build:weapp`，然后用微信开发者工具打开 `dist/weapp`。AppID 为 `wx8244fb803ec1b65b`，合法域名校验开启。主包保留兼容入口 `pages/schedule/index`；中心、归档、比赛、经理、图片工具、目录、排行榜、关注、选手、队伍、图谱、回顾和晋级分别进入 13 个分包。构建末尾检查主包与每个分包不超过 2 MiB，实际预览打包单列验证。保持入口的内置方法与 Intl 兼容代码，不能用网页运行成功代替微信验证。

## 共用来源

网站仍独立使用 React 19 / Vite，本试验使用 React 18.3.1 / Taro 4.3.0。模型直接引用 Stats。构建时读取当前公开页头、FC 账号入口、五项底栏、赛事上下文、目录、排行榜、选手/队伍档案及征程/分析、工作人员、地图/英雄、回顾、晋级、匿名关注空间的 JSX/CSS 及组件依赖，保留 R7/R8 的周赛、历史首页与比赛详情来源。DataLayout 的路由布局判定、导航规则和样式组合也从原源码提取。原生选择器、弹窗、滚动、表格、SVG/图表 Canvas、页面栈、语言监听和存储使用平台适配，所有导入统一到 Taro 的 React。`src/generated/source-manifest.json` 记录实际引用的设计与模型源哈希，修改原设计或模型后重建同步；不维护另一份手绘页面。

Stats 移动端正在翻新，以本轮构建时的源码为设计来源。公开页面的页面顺序、标题、卡片、筛选和详情页签均由原组件生成；横向容器保留作者的内层 grid/flex，微信外层负责滚动。公开 CSS 保留原 px/vw/clamp/env 单位，继承文字从原全局 body 提取；表格说明与硬换行/可选断行使用微信支持的组件，保留原文。账号入口沿用原 FC 外观，点击明确说明登录尚未接入。原生首页通过下拉刷新和微信菜单分享，更新失败时保留明确重试入口。图表/图标、网页电影动效和分享编辑器存在平台边界，不能把源码复用称为所有浏览器效果逐像素一致。主要开发阶段及完成条件记录在 [移植设计](specs/stats-parity/design.md)。

`npm run build:h5` 是适配器构建检查；本轮主要交付与交互验证为微信原生小程序。网页辅助服务仅允许四个指定公开快照路径。此次没有上传体验版或发布，也没有迁移 System 数据库。
