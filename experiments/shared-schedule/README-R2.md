## R2 开发记录

FCW26 的公开查询与本机关注初版。React 页面组件同时生成 H5 和微信小程序；构建读取 Stats 当前移动端设计与赛事模型，生成文件不单独维护。

### R2 功能

- 总览：公开周次、重点对阵、五局进程、周期积分和队伍关注。
- 赛程：周期／周次、队伍、搜索和状态筛选；详情显示五局记录，返回保留筛选。
- 数据：最新已公布周期积分，保留官方顺序和并列名次；选手每 10 分钟数据按指标排序，说明样本和赛季范围。
- 参赛阵容：队伍与选手搜索、职责和队伍筛选、分页；队伍资料区分当前目录与当周锁定阵容，选手资料显示已公布统计。
- 我的：本机关注的队伍、选手及其公开比赛。关注不需要登录，不跨设备同步。
- 更多：完整六个 Stats 入口，包括晋级形势。资格、名额和日期以公示为准，不从积分榜推算晋级结果。

底栏沿用「总览、赛程、数据、我的、更多」。六个查询视图共用一个原生页面控制器，详情通过微信页面栈导航；底栏为共用组件，未配置原生 tabBar。

第二轮构建标记为 `public-mvp-r2-20261001`。目录和数据页的搜索、筛选、选项与分页由页面控制器保存，切换底栏、刷新或从详情返回时保留；不保存到设备存储，重新启动后恢复默认查询。顶部刷新保留已有内容，显示成功读取时间（北京时间）；该时间不是服务器发布快照的时间。更新失败继续显示上次记录及明确提示。

微信端使用原生分享按钮与 `onShareAppMessage`：比赛、队伍和选手资料带具体公开路径，普通查询页分享当前页面；「我的」分享公开总览。分享只包含白名单中的公开路由字段，使用 Stats 品牌图生成的固定封面，不包含本机关注、搜索文字或运行诊断。

### 辅助运行

需要 Node.js 24、npm 和已登录的微信开发者工具。

```powershell
npm ci
npm test
npm run build:h5
npm run build:weapp
npm run serve
```

网页预览为 http://127.0.0.1:3027，微信开发者工具导入 dist/weapp，AppID 为 wx8244fb803ec1b65b，合法域名校验开启。只修改源码，构建会重写生成目录。

### R2 共用来源与适配

SharedCenter.jsx、CenterViews.jsx、SharedSchedule.jsx、SharedMobileNav.jsx 是两个试验输出共用的页面模板。prepare-design.mjs 从当前 Stats 的周赛赛程、总览、阵容目录和底栏 CSS 生成手机布局，读取同一份颜色、字号、字体、导航文字和图标。模型直接引用 weeklyScheduleModel.js、weeklyOverviewModel.js、weeklyAdvanceModel.js，英雄、地图与队标使用现有解析器。

src/generated/source-manifest.json 保存源文件 SHA-256。原设计变化后重建即可同步样式；平台选择器、弹层、存储、请求和页面栈适配独立维护。不能将两个试验输出成功称为所有 Stats 页面已经共用组件：现有网站仍使用 React 19.2.4／Vite 8，本试验独立使用 Taro 4.3.0／React 18.3.1。

微信 HTML 适配不渲染 table/tr/td；共用 StatsTable 使用受支持的 div/span 节点，保留 Stats 表格选择器类、行列样式和 H5 可访问表格角色。CSS 转换保留 nth-child 算式，手机布局按原顺序合并所有适用的中间断点。适配 CSS 处理微信布局差异和底栏安全区，不另建一套品牌设计。

只支持简体中文。字体 OFL 与 FormatJS 许可证随输出保留。入口提供 core-js 及 FormatJS 日期／数值格式化兼容；原生 Intl 可用时保留原生实现。时区数据从依赖的 IANA 数据生成，仅包含 Asia/Shanghai，不手写时区规则。

## 数据和边界

微信直接读取 https://admin.fries-cup.com/api/public/seasons/FCW26/publish/latest/data。H5 本机代理仅允许同一个公开入口，监听 127.0.0.1。初版不含账号、报名、支付、后台写接口、密钥或 CloudBase 数据迁移。

首个请求由原生 onLoad 启动。读取同时监听原生回调与 SDK Promise，有独立 20 秒截止时间；并发更新共用一个正在进行的请求，失败后可重试。失败提供重试／连接检测，缓存回退有明确标记。渲染错误边界提供重新打开入口；安全运行诊断记录构建标记和公开数量，不保存响应头、身份标识或请求正文。

关注保存在 friescup:FCW26:following:v1，与其他赛事隔离。读取损坏或保存失败会明确提示；写入失败保持原来的关注状态，公开记录中暂时缺失的关注对象保留 ID。

当前为开发预览；正式手机、体验版上传、备案、认证和发布审核是独立验证门槛。实际证据与限制见 VERIFICATION.md。
