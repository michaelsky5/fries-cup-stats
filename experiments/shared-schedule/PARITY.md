# Stats 功能对照

用户确认先公开查询与历史赛事，再账号与参赛。下表记录 R9 原生实现；公开设计来源统一不等于账号、全部网页动效和导出工具已完成移植。R4 四赛事查询已获用户安卓验收；R9 安卓验收、体验版与正式发布分别记录。

| Stats 功能 | 原生小程序当前对应 | 状态与边界 |
| --- | --- | --- |
| 新版移动设计 | 原页头/FC 入口/赛事上下文、底栏/更多/语言菜单，以及下表全部已接入公开查询页面；DataLayout 布局与导航纯判定 | 构建时转换当前 JSX/CSS 和依赖闭包；根 Stats 源文件未修改。微信 API、图表/SVG、网页动画和导出编辑器的边界单列；R9 安卓验收待完成 |
| 四赛事目录、首页与归档 | FCW26 / FCR26 / QGCS4 / FCA26 切换、总览、历史入口 | 真实公开快照，缓存、关注、返回与分享按赛事隔离 |
| 周赛总览、赛程、晋级 | 原周赛模型、RR5 五图、公开周期/周次、官方周期积分 | 保留公开名次和并列，不从积分自行生成资格 |
| 历史赛程、比赛详情 | 阶段/轮次/赛制/状态/队伍/搜索；原 SignalMatchDetail 的概况、走势、MVP、逐图战报、完整数据、选手筛选/对比和公开资料 | 详情返回原页面/筛选；查询使用微信支持的 forEach，表格原生横向滚动，公开分享只保留地图选择 |
| 晋级与 standings | 瑞士轮、分组、突围、淘汰、最终名次 | 复用 Stats 赛制模型；QGCS4 四组可切换 |
| 阵容、队伍、选手 | 原 RosterHub / Players / Teams 目录；原档案、赛季征程、竞技分析、共同出场与相关比赛组件 | 原结构与样式直接生成；公开深层阅读参数、目录筛选和详情返回保留；图表使用真实数据的原生 Canvas 适配 |
| Staff / roster | 原工作人员目录、职务筛选、档案和相关身份页面 | 原结构/CSS 与公开身份解析；不暴露私有联系方式 |
| Leaderboard | 原 KprLeaderboard 及指标、统计模式、排序、时长/样本/队伍/英雄/关注筛选与对照弹窗 | 最多四条同职责对照；正式/暂定/未评级；原 OVR 贡献与对手说明；选择器/勾选/滚动是微信边界 |
| 地图 / 英雄 | 原地图索引/详情、英雄图谱与关联队伍/选手/地图及逐图证据 | 原结构/CSS 和图谱模型；SVG 使用原路径的 Canvas 适配；频次不称为上场时长 |
| 回顾入口与故事 | 原回顾入口、搜索、赛事/选手/队伍/工作人员/身份故事页面与章节 | 原页面结构/CSS、生成器与 Cinema 场景数据；原电影动画和完整导演版视觉尚未逐项复刻 |
| 导出图片 | 基础资料卡；原版纪念票/登机牌、纵向电影海报、电影票、导演版 | 四格式、票面样式、代表英雄、人物大小/位置、公开二维码已接入原生 Canvas；模拟器实际 PNG 已验证，手机生成/相册授权仍待验收。原阵容/展览/签名导出尚未迁移 |
| 我的 / following | 原匿名 FollowingWorkspace，按赛事保存的本机关注、主要队伍和相关比赛 | 原页面结构/CSS；无账号、无跨设备同步；账号与云端关注属于下一阶段 |
| 多语言 | 简体中文、繁体中文、英文、韩文选择器与原语言契约 | 共用 Stats 字典、英雄/地图名称、故事本地化；缺失的原文案仍沿用原回退。四语言渲染检查已通过，原生及手机证据详见验证记录，不称为全部翻译重新校对 |
| 经典经理 fantasy / battle / shop / champion / career | 原版页面、引擎、商店、训练、战术、赛后表、生涯、冠军图卡 | 本机存档按赛事隔离；原生实际组队/训练/四图比赛及重新打开已验证，测试存档已恢复。冠军图卡为测试入口验证，未声称赢得该场比赛；手机待验收 |
| Scouting 专属报告 | 尚未接入 | 保留访问门槛；随账号与权限适配，不改成公开报告 |
| Account / participate / activate / match room / tasks / communications / prediction | 尚未接入 | 下一阶段复用 System 身份和权限，不以微信登录直接授予参赛权限 |
| 开发预览路由与私有试用赛事 | 未引入公开目录 | 不发布开发路由，不执行 Web 环境开关来发现私有赛事 |

剩余公开适配：原电影播放动画、网页队伍分享编辑器、展览/阵容/签名导出，以及 R9 新布局、语言、经理和高级图片的真机验收。选手/队伍分享入口目前打开已有原生纪念票/海报工具，不称为全部网页分享模板和编辑器已迁移。随后接账号、我的空间、报名/激活、比赛房间、任务、通信、预测及专属报告。账号接口目前使用 System 会话 Cookie 与现有身份、赛季权限；微信身份不自动取得参赛资格。
