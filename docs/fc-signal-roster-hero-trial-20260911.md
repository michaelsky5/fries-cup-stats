# 阵容总览：名单联动英雄试作

日期：2026-09-11。范围：本地 `/roster?design=kpr5` 试作。

## 展示规则

- 默认从有已收录英雄记录的成员中，按累计出场时长降序选择展示对象；时长相同或均缺失时比较已收录地图数，再按姓名和 ID 稳定排序。未知时长保留为未知。名单自身仍按职责和姓名排列。
- 桌面悬停姓名或用键盘聚焦档案链接时，英雄图、姓名说明和名单上的细金色标记一起更新。移出后保留最后浏览的对象；切换队伍后重新选择该队的默认对象。
- 姓名点击和 Enter 仍打开原来的选手档案，保留队伍及赛季的返回语义。英雄预览是当前卡片内的临时浏览状态，不写入 URL。
- 缺少英雄记录时展示本队队徽与“暂未收录英雄记录”；不借用其他选手的英雄，也不把缺少收录解释为从未参赛。
- 立绘占卡片宽度从 36% 收到 32%，缩小画幅。底部明确显示选手名、英雄名及浏览提示，文字区域使用纸色渐变保证短卡片上的可读性。
- 切换使用 220 ms 淡入，遵循减少动态效果设置。宽度不超过 1100 px 时隐藏立绘和对应标记，以完整名单为主。

## 数据核对

FCR2026 的默认展示由原来的 37 位重装选手、1 队无记录，变为 7 位重装、13 位输出、17 位支援，另有 MNW 暂无可用英雄记录。这个结果来自相同公开快照和统一规则，没有按职责手动分配。

ECNU 默认展示 3e 的瑞稀；悬停红豆显示芙蕾雅，聚焦轩轩显示西格玛，聚焦八啊哥显示无英雄记录的说明。全季 9 位成员及季后赛加入、退出注记完整保留。
