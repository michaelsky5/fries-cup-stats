# Weekly cycle date display

The public cycle selector shows announced start and end dates, including periods that cross calendar months. Dates are displayed in Beijing time and localized with the current interface language. Missing or invalid bounds omit the date line.

This incremental release uses the latest main baseline, including shared registration, optional coach fields, country selection, automatic visitor locale, mobile navigation and the inline EdgeOne locale/proxy fix. No standalone locale function, data fixture or private API record is published.

Validation: full lint (no errors; eight existing shop-page warnings), account UI contracts, weekly public tests 68/68, visitor locale tests 7/7 and production build. Live deployment and browser evidence are recorded separately in the local release proof directory.
