# 团队环境模型继续分析：保留当前公式

2026-09-06。进一步分析后，建议暂时保留当前 v1.4 公式。队友当场共同波动是明显的关联，但本轮尝试将历史团队偏差用于后续预测，并未得到可接入的改善。现有 OVR 在同队同职责的比较中已经具有一定统计表现参考价值。

## 这次修正了什么判断

上一轮本人残差与队友平均残差的相关约为 0.75，说明队友往往在同一张图共同高于或低于此前评分。它并不说明这种共同偏差会延续到下一场，也不能直接用作团队校正系数。本轮明确检查了时间上的延续性。

沿用原 474 个选手职责场次、60 场、18 日，以及完全相同的历史评分与目标。数据 SHA-256：`a22f3f4c44c56e9349adfd7cf1bf93a1e7770a69913a02b5ef810673f485f08a`。参数和预测始终只使用更早比赛日；当天队友表现、当天赛果、英雄和地图时长不进入团队项预测。

## 历史团队偏差加收敛，没有改善误差

先将每场队伍内合资格选手的预测偏差平均，一支队伍一场只算一个样本。团队项为过去这些偏差之和除以「已有场数 + K」，相当于向零收敛。K=4 是本轮预先固定的候选，K=1、8 只作敏感性检查，没有挑选其中最好的一项接入。

| 方法 | 后续原始表现平均绝对误差 | 同日同职责成对排序匹配率 |
| --- | ---: | ---: |
| 当前样本收敛分 | 11.831 | 55.1% |
| 团队项 K=1 | 12.520 | 55.6% |
| 团队项 K=4 | 12.088 | 56.5% |
| 团队项 K=8 | 11.957 | 56.1% |

K=4 相对当前的误差增加 0.257，按比赛日重抽样的探索区间为 `[-0.177, 0.863]`，包含零。跨队排序点估计略有提高，但不构成误差和个体区分同时改进的证据。全部三种收敛强度的误差点估计都更高，因此本轮不支持接入这一团队项。

363 个观测已经有团队历史可用。K=4 的平均绝对改动约 2.59、最大约 10.38 个原始表现分；只有一场历史时，最大改动仍可达到 8.40。这些不是网页 OVR 改动，也不是估计区间，说明简单收敛并不保证每个少样本案例的改动都小。

在此前队伍 Elo 低于 1500、且个人此前分数高于本轮同队同职责同伴的 32 个观测中，11 个被团队项下调，平均项为 +0.60。这个筛选不是独立技术标签，不能据此声称已经保护或识别了弱队中的高技术选手。

## 新的正面证据：现有 OVR 在同队比较中有参考价值

只比较同队、同职责的两名选手，且两人在同一批地图中完整出场，累计共同出场至少 10 分钟。目标是「下次共同地图中，谁的原始统计表现分更高」。两人此前都已经达到正式评分资格。

共得到 169 个配对场次，覆盖 57 对不同队友、28 支队伍、57 场、18 日。当前 v1.4 OVR 的排序匹配率为 **62.7%**：101 个明确正确、10 个预测同分，同分计半。按比赛日聚类的探索区间约为 57.1%–69.2%，按队伍聚类约为 55.9%–69.7%；每对队友等权后的匹配率为 61.6%。

这是本次更窄比较范围内的参考证据。不能把它与上一轮跨队比较的 55.1% 相减，宣称「校正后提升了 7.6 个百分点」：样本、比较对象和目标都不同，当前 OVR 也没有被修改。

这些结果仍是当前指标定义的统计表现，不是独立技术标签。配对与实际地图只定义检验样本，不表示能提前知道谁会上场；重复队友和同队记录并不独立，探索区间也没有解决同赛季开发选择的问题。

## 历史队内分差没有超过现有排序

另试了一个直接方法：将两名队友过去共同出场时的原始分差平均，并按 3 场中性经验向零收敛。没有配对历史时沿用当前分差。共有 112 个配对场次已经具有更早的共同记录，所有方法在这同一批数据上比较。

| 方法 | 匹配率（预测同分半计） | 原始分差平均绝对误差 |
| --- | ---: | ---: |
| 当前样本收敛分差 | 63.4% | 8.740 |
| 当前 v1.4 OVR 差 | 64.3% | 不同尺度，不比较 |
| 历史队内分差加收敛 | 63.4% | 7.909 |
| 始终预测同分 | 50.0% | 8.244 |

分差幅度的误差下降了，但谁更高的判断没有增加：历史方法与当前原始分差均正确 71 次。准确率差值的探索区间约为 -8.8 到 +8.6 个百分点，不能说明排序改进。

支援的 54 个有历史配对中，历史方法从当前原始分差的 37 次正确变为 39 次；输出的 58 个配对则从 34 次降到 32 次。只有两次判断的变化不足以宣布支援模型升级。重装没有同队同职责配对，不能套用这一结论。

另一个结构事实是，共享团队项在同队两人相减时会抵消。本轮它改变同队原始分差的次数为零。团队项即使让跨队排名变化，也不会因此增加同队个人区分能力。

## 为什么现在无法轻易拆出独立个人实力

正常日志中的 230 个玩家 ID 分属 37 支队伍，所有 ID 都只对应一支队伍。没有直接的跨队 ID 记录；不同注册 ID 是否属于同一真实玩家，也没有在此合并推断。

对于「个人常数项 + 队伍常数项」模型，如果给某队队伍项加 c，同时给该队每个个人项减 c，所有预测总和不变。当前记录无法单独确定应该如何分配。先验和约束可以固定一种分配，但结果会依赖这些假设；不能把它包装成由数据唯一识别的个人技术能力。

这是对当前数据和这种加法模型的具体限制，不是说任何统计研究都做不了。相关方法依据见 [Stan 对重复截距和模型识别的说明](https://mc-stan.org/docs/stan-users-guide/problematic-posteriors.html#collinearity-of-predictors-in-regressions)。

## 现在的建议

暂时保留 v1.4 评分公式，将它定位为同赛事、同职责条件下的统计表现参考。同队可比场景提供了一定支持；跨队差异仍应结合赛程、英雄、样本和队伍环境解释，不能直接等同于纯技术差距。

本轮没有找到应当立即接入的新公式。下一次候选评估沿用已固定的误差、排序、队内比较和小样本检查，优先等待新增比赛或独立赛季检验，避免持续在这一份赛季数据上选参数。地图内英雄时长等更细记录若后续可获得，可作为新的可检验信息来源。
