# 组队大厅联系候选

本轮维护集成 M1 后补齐 M2：个人向队伍、负责人代表队伍向个人两种联系，双方逐次明确 QQ 授权，收到／发出／全部记录，撤回、结束与撤销，以及本人消息和管理限制结果。接受联系不改变正式报名、阵容或参赛资格。

联系表单默认不勾选授权。QQ 只保留在当前组件，退出页面或切账号时清空；待回应不读取 QQ。已联系状态须主动点击查看或复制，服务器每次重新验证双方与当前负责人。失焦、页面隐藏、30 秒超时、撤销或权限变化后停止显示。

页面支持简中、繁中、英语、韩语。显式界面词典覆盖表单、状态、帮助和系统消息，不翻译队名、个人介绍、联系留言、管理员原因。语言切换不会放弃草稿；真正离开页面会要求选择继续填写或放弃。普通正文使用用户确认的设备字体方案。

用户指定反馈由赛事负责人处理。候选从 API 获取已核对的赛事 QQ 群 `1050253727`，提供群号复制及手动复制失败提示；群内仅提交记录编号和问题概述，不公开密码、验证码或私人 QQ。没有编造加群链接。

本地证据：System 的 `check-team-lobby-browser.mjs`、`check-team-lobby-contacts-browser.mjs`、`check-team-lobby-locales-browser.mjs` 合计 30 条真实 Edge 流程；使用合成账号和 QQ、仅连接本机隔离 PostgreSQL。四语言覆盖 390×844 和 1440×1000，草稿保持、双方授权、撤销、限制/解除、退出清除与反馈复制成功/失败通过。页面截图已检查；并非真实手机、真实邮件、QQ 加群或生产验收。

五组本地纯函数检查覆盖安全续接、状态标签、语言切换草稿和人工消息保留，ESLint 与构建通过。最终完整 CI 仍留在全轮优化候选完成后；没有逐项运行 CI、推送或部署。联系开关和大厅 WRITE 模式在 System 一侧控制，候选默认关闭。真实邮件、密钥恢复、容量、设备及生产验收仍为开放门槛。
