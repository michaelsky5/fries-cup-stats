## 调整

1. 比赛房压缩标题、统计和阶段说明。历史比赛保留在桌面左侧，手机通过“切换比赛”展开。房间、口令、赛管安排与双方准备状态集中展示；黄色主操作位于准备状态之后。当前准备阶段明确高亮。
2. 协作资料加载时预留空间，减少深链接定位后因异步内容出现而发生的页面跳动。协助请求、补充和处理历史仍在本页，进行中和只读状态按服务返回的权限与原因展示。
3. 核心登记和出赛名单采用同一套选手行，分别展示姓名、BattleTag、职责与核心标记。桌面名单与核对区并排；手机底部操作区显示当前人数或未满足的要求。草稿、未保存、已提交等待锁定和正式锁定分别说明。
4. 保留既有身份、周次、修订、指纹、提交回执和未保存离开保护。未调整正式 API、数据库或赛事规则。
5. 修正页面总览样例接口读取错误名单字段的问题：现在按真实页面的 `members` 请求保存，并增加保存、提交、重新读取后成员仍保留的回归检查。
