# 比赛房首图选择权与配色 · 2026-09-12

本轮按“赛季设置默认模式，每场赛前可覆盖”实现首图选择权；同时调整比赛房配色和石头剪刀布图标。所有配置操作与验证均在本机合成赛事中完成，未部署、未修改正式赛事配置。

## 规则与操作

| 首图模式 | 确定方式 | 房间行为 |
| --- | --- | --- |
| 石头剪刀布 | 双方队长或经理分别提交；同时揭晓，平局再开一轮 | 获胜队伍选择地图及本队先 Ban／后 Ban |
| 高种子优先 | 赛管核对本场已发布配对的种子快照，数字较小者优先 | 确认后直接进入选图，不出现出手步骤 |
| 赛管指定 | 赛管选择队伍并填写双方可见的决定依据 | 可记录抽签、其他小游戏或赛事规则决定的结果；不会模拟一次石头剪刀布 |

- System“赛程安排 → 本届地图池与选禁规则”设置赛季默认方式。“启用网页选图和双方 Ban”与首图决定方式分开表达。
- 本场赛管或管理员可在首图流程开始前选择沿用默认或覆盖模式，必须填写公开原因。队伍不能修改模式。
- 首图流程一旦开启，即使比赛尚未进入游戏，也锁定本场模式和决定依据，避免看到结果后重选。配置调整本身不会把未开始的比赛或赛季误锁定。
- 兼容已有石头剪刀布记录；模式复用既有规则中的 `game` 字段，不改变旧 RPS 规则签名结构。
- 高种子来源目前按配对发布时的快照实现，这是等待主办方进一步确认的实现假设。核对配对版本、周次、双方队伍及参赛记录；不读取实时积分榜，不按 A/B 位置推定顺位。缺失、同顺位、不匹配或未发布均阻止确认，允许赛管在开始前改用其他模式。确认后保留快照依据。
- 后续规则保持：上一图败方选择全部；平局保留上图选择方并重新选图和 Ban；具体地图不重复，五类型完成后重开类型；地图池仍为已确认的 14 张、不含攻防阵线。

## 视觉调整

本节记录首图模式实现时的第一版配色。用户随后选择「深色框架＋暖纸色操作区」，当前方案与本轮独立检查见 [深浅分区配色记录](weekly-room-color-hierarchy-20260912.md)。

按当前 `fries-cup-data-signal-design-system.md` v2.5.13 的 Control 页面原则，保留同页主操作、名单和比赛沟通。比赛房使用局部配色变量：炭黑背景 `#171819`、面板 `#202123`、较亮操作面 `#292b2e`、沟通／输入底色 `#121315`、暖白文字。品牌黄集中到当前步骤、选中项和主要操作；错误、成功等继续使用语义状态色。没有更改全站导航结构。

出手按钮改为统一单色 SVG 线稿，保留中文名称、选中标记、禁用状态和键盘焦点。演练工具条改为中性深灰，并从宽屏房间的视口高度中扣除其 40px 占位。补齐帕拉伊苏的重音文件名及香巴里寺院英文全名图片别名，14 张地图均能解析到现有本地图片。
