# 赛季回顾入口与阅读导航精修

日期：2026-09-13

本轮完善常规赛回顾的查找入口、赛事直达入口和阅读返回流程，沿用「重新放映」的叙事气氛与已有故事内容。

## 页面变化

- 纸色区域用于搜索个人、队伍和职员档案，墨色区域用于直接观看整届赛事回顾。
- 保留选手、队伍与经理教练、赛管、解说筛选。观众通过赛事入口进入，无需先选择身份。
- 移除自动识别、实时匹配、重复搜索说明和默认的零结果面板。
- 桌面搜索结果使用通栏网格，避免长列表旁留下空栏。手机顺序为搜索、结果、赛事入口，输入与结果之间不插入其他内容。
- 无匹配时提供查找提示与恢复全部身份的操作；统计只显示当前呈现的档案数量。
- 搜索词与身份写入入口 URL；进入故事时记录返回入口，切换章节与语言后仍可返回原查询。分享章节链接继续只包含赛季、语言、人物视角、设计版本与章节。
- 桌面章节索引增加标题，选中章节在索引中保持可见。手机保留章节选择与长文滚动。
- 修复英文、韩文搜索结果中赛管职责说明的漏译；窄桌面收起会挤出 Hero 的装饰档案牌。

## 本地验证

- FCR2026 中文、英文、韩文入口；搜索 SKY、照井龙；角色筛选、无匹配恢复、清空、方向键和 Enter。
- 选手回顾从入口进入、跳转终章、切换英文、退出后恢复 SKY 查询；赛管回顾与赛事回顾直达、手机章节选择与返回。
- 390px 手机英文长信滚动到落款；320px 中文入口与赛事回顾；1024px 英文入口；正常桌面宽度。检查外层页面横向溢出，保留有意的长文内部滚动。
- FCA2026 原有身份入口和 `design=original` 回退仍可加载与展示结果。
- 回顾精修回归检查、回顾赛季检查、定向 ESLint、隔离目录构建与 `git diff --check`。

完整赛季检查覆盖 365 份故事、730 份本地化故事、158 个引用素材，无警告或错误。新增回归覆盖查询返回、跨赛季与外部返回地址回退，以及职责短语翻译顺序。
