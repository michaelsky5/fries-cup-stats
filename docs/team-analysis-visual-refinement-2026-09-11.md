# 竞技分析：视觉与阅读层级升级

本轮在「速览 / 详细分析」两种阅读方式上继续调整构图。参考薯条杯官网的黑色主视觉、纸面档案和有限黄色强调，把主张与依据放在同一个阅读区域。队伍展厅、赛季征程不在本轮重做范围内。

## 这版的变化

- **速览重点**：最主要的观察占据整行，左侧给出判断与核对入口，右侧用纸面图解显示同一批真实样本的双方数值、地图数和交手数。次要观察缩为紧凑栏目，保留各自入口。
- **比赛入口**：突出真实比赛的日期、对手、比分与轮次；对应观察超过两场时，明确标注首场与最近一次交手。补齐 `UB Final` 的中文轮次名称。
- **成员速览**：选手名字与其记录最多的英雄共同构成视觉主角，明确说明英雄图片的含义。没有英雄记录时沿用共享黑影轮廓；没有出场记录时不生成表现数值。
- **指标对照**：桌面显示选手、同场同职责对手、差异与明显的点击入口。手机将每个指标重排为两行，先读自己的数值，再读参照与差异；隐藏不再共用等宽区域的短条图。
- **详细分析**：宽屏使用左侧专题目录，显示团队、成员、英雄、对手与地图的当前范围数量。中等屏幕回到横向目录，手机使用三加二排列。当前专题仍按需挂载。
- **页面头部**：减少重复队标与分隔带，把队名、赛季数据、赛段选择集中编排；两种模式按钮增加用途说明。
- **动效**：仅添加短暂的内容切换与数据条进入效果；两个新增样式模块均设置 `prefers-reduced-motion` 覆盖。

没有改变分析聚合、样本门槛、指标推荐、研判逻辑及 URL 选择状态函数。图解只呈现已有观察中的数值，不增加新的强弱判断。速览数据仍可进入相应专题核对。
