# 赛季评分 v1.4：对手强度校正

本地候选，2026-09-06。对手强度进入赛季 OVR；保留 v1.3 的原始表现、样本收敛、正式／暂定／未评级规则和基础 OVR。点击评分可查看原分、实际调整、最终分，以及逐场对手历史。

## 校正规则

- 每支队伍从 1500 开始，用正常完成的系列赛胜负更新 Elo，K = 32，平局取 0.5。系列赛长度不增加权重。
- 按赛事时区 Asia/Shanghai 的比赛日处理。当天所有比赛读取前一天结束后的评级，再统一累加当天结果，避免把同时进行或尚未结束的同日比赛当成已知战绩。
- 只使用有明确比赛标识、有效日期、双方队伍 ID 及一致赛果的正常比赛。弃权、判罚、轮空、未完成比赛、冲突或缺失赛果不影响评级。空分数不当作 0 比 0。
- 不读取最终排名、赛季 OVR 或数据发布时间来定义对手实力。比赛的规范 ID 优先于旧的原始 ID；重复、歧义标识不猜测。历史记录必须注明队伍，不能用现在的名单反推。
- 对手权重 `h = min(对手此前正常场数 / 3, 1)`。按本职责英雄记录的实际出场时间，加权 `(对手评级 − 1500) × h`，未匹配时间也保留在总时长分母中，贡献为 0。
- 上述平均评级差除以 50，再乘 `min(本职责已匹配正常场数 / 3, 1)`，得到校正量。限制在 ±3，正负对称四舍五入，最后再次遵守 60 的下限和原有样本上限。
- 暂定评分仍不进入正式名次与职责分位，最高 89；未评级不生成数值。最终正式榜单按校正后的 OVR 排序，同分沿用原表现排序。基础职责分位不因校正重新计算，避免重复放大影响。

Elo 更新：`R_A += 32 × (S_A − 1 / (1 + 10^((R_B − R_A) / 400)))`，另一队反向更新。同日每场使用同一份日期开始时的评级。

50 点／OVR、3 场收敛和 ±3 上限是保守的产品规则，尚未通过跨赛季数据拟合成个人表现的因果校正。队伍使用固定队伍 ID 追踪，阵容变化与游戏版本差异尚未单独建模；这是按比赛日期重建的历史评级，不是当时网页发布内容的逐次存档。
