# 三目录页头与操作细化

日期：2026-09-11。状态：本地实现、浏览器检查与最终构建通过；未提交、推送或部署。

## 实施范围

本轮延续用户认可的三目录共同框架，实施讨论中优先级最高的页头整理和名单操作说明，同时检查手机展开后的阅读长度。主视觉构图和记录口径沿用上一轮。

- `/players`、`/teams`、`/staff` 的 `design=kpr5` 页头使用一个赛事与数据状态区。赛事名称、归档或进行状态、数据时间、失败或来源说明、重试入口集中呈现，去掉重复栏目编号和另一条更新通知。原版、阵容总览及详情继续使用各自现有上下文。
- 名单按钮显示“预览／查看中”；独立的“档案 ↗”链接具有完整可访问名称和文字提示。职员链接按真实去向显示“队伍／回顾”，无已发布回顾时没有链接。搜索采用放大镜；关注采用“☆ 关注／★ 已关注”，并说明关注或取消关注的具体对象。
- 手机点击名字展开后，该行可直接收起；预览顶部的收起按钮随正文保持可见，底部提供返回名单入口。关闭后恢复原名字的焦点及可见位置，不把默认首项显示为已展开。宽窄屏切换时仅渲染当前布局需要的预览正文。
- 队伍标题区的关注数量与管理入口按词组换行，避免在手机上拆开“管理关注”。
