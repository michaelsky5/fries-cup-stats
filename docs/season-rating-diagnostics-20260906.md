# 评分误差来源：团队环境是下一步研究重点

2026-09-06，本地离线分析。结果支持优先研究团队环境与个人表现的关系；目前仍没有足够证据把一个固定补分方案接入网页。当前 v1.4 OVR 保持原样。

## 这次检查了什么

沿用同一公开快照与同一时间验证样本。数据 SHA-256：`a22f3f4c44c56e9349adfd7cf1bf93a1e7770a69913a02b5ef810673f485f08a`。原来 474 个选手职责场次展开为 1,327 条地图记录，覆盖 167 张图、60 场、18 个比赛日。

每张图的原始表现分使用该比赛日之前的英雄基线计算。按分钟重新汇总后，与原验证的全部 474 个目标吻合，最大浮点差约 `1.42e-14`。原验证的平均绝对误差仍为 11.831，没有换样本或更换目标。

残差定义为「本场地图原始表现 − 此前样本收敛分」，用于检查评分与后续表现的差异。每场比赛总权重相等，场内选手职责等权，再按地图记录分钟分配。地图记录层面的误差与场次层面的误差分开报告。方法参考 [残差诊断](https://otexts.com/fpp3/diagnostics.html) 与 [时间滚动验证](https://otexts.com/fpp3/tscv.html)。

## 最明显的信号：队友一起偏离预测

1,303 条地图记录具有至少两位其他合资格队友，覆盖 59 场、18 日。本人残差与其他队友平均残差的加权相关为 **0.753**；约 **76.9%** 的权重下，两者方向一致。

计算队友均值时排除本人全部记录，并排除对手和其他地图。这样避免将本人分数混入对照后制造相关。仍需注意，同队记录和跨日选手并非独立样本；这个相关系数不是团队因素的因果贡献百分比，也不是可直接采用的 OVR 校正系数。

赢下地图的记录平均比此前预期高约 **8.52 个原始表现分**，输图记录低约 **12.57 分**。扣除其他队友的共同偏差后，两组差值均接近零。这与「队伍一起发挥较好或较差」相符，但无法区分协同、个人作用、对手实力或地图节奏各自的影响。

这说明要研究技术层面的个人区分，除了绝对统计表现，还需要检查同队环境下的相对表现。直接减去队友均值也可能抹掉个人带动全队的贡献，因此它目前只作为诊断参照。

## 英雄和模式有偏差，固定补分尚未奏效

固定检查英雄、地图模式、队伍、对手赛前 Elo 档位、双方 Elo 差、地图时长六个因素。每个因素单独实验，不叠加或搜索组合。参数只用以前比赛日的残差学习，至少需要 20 个选手职责场次、8 场、4 日、5 位玩家；不足时回退职责平均偏差。

| 条件校正实验 | 场次平均绝对误差 | 成对排序正确率 |
| --- | ---: | ---: |
| 当前样本收敛分 | 11.831 | 55.1% |
| 只修正职责平均偏差 | 11.782 | 55.1% |
| 再按英雄修正 | 11.850 | 55.2% |
| 再按地图模式修正 | 11.863 | 55.1% |
| 再按对手赛前 Elo 档位修正 | 11.646 | 54.1% |
| 再按双方 Elo 差修正 | 11.773 | 55.1% |
| 再按地图时长修正 | 11.779 | 54.9% |

对手档位的误差点估计略低，但排序点估计也下降；相对职责对照的误差差值为 -0.136，探索区间 `[-0.603, 0.221]`。这轮没有出现可以稳妥接入的方案。

队伍固定偏差另有一个样本限制：29 支入样队伍中，只有一支到完整观察期末达到门槛，且达到门槛后没有新的可检验记录。该因素在检验中的启用权重为零，不能用它与对照相同的结果判断队伍校正无效。后续更适合研究共享信息、对小样本收敛的团队环境项。

英雄、模式、最终地图时长和实际参赛信息属于当场条件。本实验给定这些条件后检查历史偏差是否延续，**不是提前知道这些条件的赛前预测**，也不是个人技术评分已获验证。本场胜负和队友本场表现从未用于这些历史参数的拟合。

## 为什么不能看到英雄偏低就直接加分

在满足门槛的分组中，有 5 个英雄组和 4 个模式职责组在日期前后两半均出现同方向偏差。但这些条件与队伍、对手、选手专精重叠，不能直接解释成英雄或模式自身的评分缺陷。

例如，Tracer 记录的平均偏差约为 -4.00，扣除其他队友偏差后的相对值却约为 +2.00。使用该英雄的选手可能与全队一起低于此前预期，却没有比队友低得更多。这个例子说明，按原始偏差固定补分容易混入团队环境。

面对赛前 Elo 高于 1525、且已有至少 3 场历史的对手，重装、输出、支援的平均偏差分别约为 -5.79、-5.58、-5.03；与其他队友比较后的差值分别约为 -1.48、-0.14、+0.68。三类职责共享了相当一部分同向变化，但这些比较仍然只是关联证据。

分组筛选、前后方向和所有六个实验均完整保存在报告中。按比赛日重抽样的区间未校正多重比较、同赛季开发选择或跨日重复玩家，不能当成新赛季确认结果。

## 数据能支持到哪一层

全部 2,840 条正常记录都有可识别英雄、与比赛记录一致的地图模式、历史队伍和地图时长。对手至少有 3 场历史的覆盖为 1,625 条，双方均满足该条件的为 1,520 条。

不过，全部记录都没有独立 `rowTime`，记录分钟均等于地图总时长；同一选手职责地图只有一个英雄标签。现有数据适合地图和比赛层面的统计研究，不能由这些标签还原精确换英雄时机、逐段阵容或技能操作。

## 下一项具体工作

优先做团队环境与个人相对表现的离线候选：保留绝对统计表现作为对照，研究带小样本收敛的共同环境项，并单独检查同队同职责选手的区分情况。评分效果需要同时看后续误差、排序、弱队高表现选手及低样本行为；当前同队相关性只能提供研究方向，不能直接确定新权重。

输出先保留在离线报告中，用新赛事数据进一步检验。网页继续使用当前 v1.4 评分和解释。
