日期：2026-09-05。范围：赛程精选 → 完整列表 → 比赛详情 → 返回原筛选。依据：[视觉复核与计划修订](fc-signal-visual-audit-and-rebaseline-20260905.md)。

**本批已提供可运行的新结构，并完成下列本地检查。视觉仍待用户从预览评审；全站正式替换、进行中赛事和账户业务没有因此完成。**

## 实际变化

- 精选页保留 Archive 叙事，缩小竞争标题与留白，提高辅助文字字级。决赛保留在首屏，其后的关键战改为三列卡片，手机单列；窄桌面标题与决赛并排呈现。
- 完整列表使用新的 `SignalMatchIndex`，收紧页头，合并查看模式、队伍搜索与筛选。阶段、结果数量、轮次和比赛行连续排列；手机使用轮次下拉框。队伍精确 ID 和名称只计作一个筛选条件。
- 轮次写入 `roundView` 查询参数。进入详情再返回可以保留阶段、队伍和轮次，搜索或重置时清理失效轮次。
- 比赛详情使用新的 `SignalMatchDetail` 组件结构：对阵/比分 → 地图进程 → 比赛分析 → 逐图记录。地图轨道不再叠加吸顶。
- 分析区统一为双方累计数据比较行和三条职责表现；保留低样本提示，补齐英文指标。录像/工作人员与附加纪录按需展开。
- 逐图统计采用一张对齐的双队表格，复用原评分、高光与角色排序逻辑。手机内部横向滚动，选手列、队伍标识和说明在横向滚动时保持可读。
- 保留每图禁用、比赛代码、时长、备注、缺统计状态、弃权结果和录像类型。胜负未知不自动写成平局；图片失败按资源地址降级，换到其他图片仍会正常尝试加载。
- 新结构受新版设计开关控制；原版详情分支仍可进入。
