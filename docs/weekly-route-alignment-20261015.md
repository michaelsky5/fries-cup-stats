# 周赛晋级路线与 C1 排期

周赛晋级形势与常规赛一样通过 `phase=points|playoffs|major` 切换阶段页面，一次只挂载一个阶段。原 `#weekly-points`、`#weekly-playoffs`、`#weekly-major` 及完整签表链接仍能定位正确阶段。阶段切换保留赛事、赛段、队伍和语言，支持刷新及浏览器前进后退。

季后赛页面先展示完整对阵图与时间，不再折叠完整签表。默认查看全部对阵，选队后高亮相关节点与连线；胜方使用实线，负方使用虚线。按队伍查看的路线保留为辅助展开面板。手机完整对阵图保留内部横向滚动，并提供滑动提示及队伍选择。共同沿用 `AdvanceSignal.module.css` 的导航、纸色标题、黄黑选队栏及路线卡片语言。

公开比赛及已审核晋级仍由 `weeklyEliminationModel` 提供。`weeklyRouteModel` 将公开记录与赛事组已确认的条件排期组成展示模型，不修改积分、正式种子、比赛记录或冠军结论。原比赛详情链接及返回位置继续保留。
