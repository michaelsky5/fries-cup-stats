## 修复

- 比赛房改为单一阶段模型、单一进度条：先手权 → 地图与顺序 → 双方首发 → Ban → 准备 → 比赛 → 本图结果 → 整场赛果。
- 首发编辑入口位于后端 `BANNING` 阶段、双方首发未齐全时；不再等待 Ban 完成才提供首发入口。只读步骤查看和当前操作互斥，可返回当前步骤。
- 有赛管时，本队操作代表仍可确认准备、确认暂停恢复；最终开赛和恢复权限仍取后端权限。
- 报名邀请成功后刷新共享登录状态，再进入报名。若刷新失败，仅重试会话同步，不重复消耗邀请。
- 桌面开局页面允许随内容增高并滚动，避免 768 像素高度下裁掉消息发送区。
- 修复已结束比赛详情未传入状态对象导致的崩溃。
- 操作代表不再被误标为队长；保留其选手、教练、经理或队长身份。
- 1V1 说明补入最新附件中的 `M94Y1（30分 10个头）`，正式比赛房设置码仍为独立字段。
