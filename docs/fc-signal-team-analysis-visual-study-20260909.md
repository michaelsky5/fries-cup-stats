# 队伍竞技分析：首屏与团队表现视觉样板

2026-09-09。本地实现与验证完成，未提交或发布。

本轮针对已确认的数据结构，重新设计首屏和团队表现两个连续区域。后续成员、英雄、趋势、对手和地图仍沿用已有内容与布局，作为下一步视觉升级的基础。

## 版面决定

1. 队伍标题、赛段选择、实际交手战绩和记录覆盖组成紧凑页头。原来的大比分封面、三张重复观察卡被整合，团队比较图提前进入主要阅读区域。
2. 主体采用左侧墨黑解读区与右侧纸色比较图。一个指标是当前焦点；黄色同时定位该行和解读中的差异值，不表示该项表现一定更好。
3. 六项指标围绕同一条参照线排列。横向位置表示相对差异，原始每 10 分钟值保持相邻；显示刻度随实际范围扩展，所有指标使用同一刻度。
4. 高频读取数值采用正常宽度的正文数字，窄粗展示字体集中用于队名、战绩和当前主要差异。
5. 手机把当前解读放在图表上方，指标行中的两方原值放到点线图下。选中指标或打开依据后定位至对应内容，并为固定页头预留位置。英文窄屏使用 Elims 短标签，按钮可访问名称及解读标题保留完整 Eliminations。

## 数据与交互

继续使用综合分析模型已有的聚合结果。相对赛事、同场双方、赢图与输图三种模式保留各自的真实数值与样本量；选中指标通过 `combatMetric` 保存，比较方式通过 `combatView` 保存。赛段选择继续作用于全页。

参照为零或任一方缺失时，相对百分比保持未知，不绘制点位；本队真实零值相对正参照为 -100%。接近零的格式化结果显示 0.0%，不出现 -0.0%。图表不将高低解释成综合优劣，也不改变原有评分或统计口径。
