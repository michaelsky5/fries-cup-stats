# 赛事中心四语言接入 · 2026-09-13

赛事中心统一支持简体中文、台湾繁体中文、韩语和英语。主导航、赛程赛果、晋级、阵容、排行榜、英雄与地图、个人空间与账号界面，以及赛季回顾使用同一语言设置。现有 FC Signal 和 original 样式均保留。

## 语言与数据约定

| 显示语言 | 内部标识 | 分享链接参数 |
| --- | --- | --- |
| 简体中文 | `zh-CN` | `lang=zh` |
| 繁體中文 | `zh-TW` | `lang=zh-TW` |
| 한국어 | `ko-KR` | `lang=ko` |
| English | `en-US` | `lang=en` |

链接语言优先于保存的偏好；主站和旧回顾偏好同步。切换语言保留赛季、搜索、筛选、章节和 URL 锚点。浏览器存储不可用时仍可通过链接切换。无语言参数的入口也会把当前偏好带入站内链接。

繁中使用台湾常用界面用语，如登入、設定、儲存、載入、資料、導覽。53 个英雄、32 张地图和 6 种模式有独立的台湾译名映射，搜索别名也能识别四种语言。队名、选手 ID、BattleTag、姓名与用户输入保留原文。比分、排名、缺失数据和评分门槛不参与文字转换。

官方名称核对来源：[英雄目录](https://overwatch.blizzard.com/zh-tw/heroes/)、[2023 年 10 月更新](https://overwatch.blizzard.com/zh-tw/news/patch-notes/live/2023/10/)、[2024 年 6 月更新](https://overwatch.blizzard.com/zh-tw/news/patch-notes/live/2024/06/)、[2025 年 6 月更新](https://overwatch.blizzard.com/zh-tw/news/patch-notes/live/2025/06/)、[2026 年 6 月更新](https://overwatch.blizzard.com/zh-tw/news/patch-notes/live/2026/6/)。

## 实现与维护

- `src/lib/locales.js` 定义语言、URL 与偏好协议；路由先加载所选语言，再提交切换。
- `src/locales/ui.json` 是通用界面词库的构建输入。通过 `npm run build:locales` 生成三个独立的语言模块，`predev` 和 `prebuild` 已接入。后续改译文应修改此文件并重新生成，不能只改生成文件。
- 运行时没有在线翻译请求。简中不下载额外词库；其他语言仅加载所选词库。约 29,000 条目标译文包含既有英韩译文、静态界面初译和人工修订。主要导航、人数/地图单位、赛程、排名、阵容、晋级和品牌用语已校对；韩语长篇说明尚未经过母语编辑逐句审校。
- `translateUiText` 只翻译词库中的界面文案。动态姓名和数字通过占位符传入。旧组件的 DOM 兼容层跳过用户输入、编辑区和登记的人名、队名。
- 回顾沿用已有英韩叙事，繁中通过 OpenCC 和专有名词规则处理已编写的叙事。转换器仅在繁中回顾路由加载。原始场景通过 Symbol 保留，章节判定与票面统计解析读取原始记录；文字测量和 Canvas 绘制使用同一译文。
- `npm run test:locales` 检查语言协议、词库占位符、生成文件一致性、名字保护、搜索别名、原始数字、回顾章节与票面昵称传递。

首轮初译只处理源代码中的静态界面文字，没有向翻译服务发送赛事记录、账号数据或用户输入。首轮关键术语校对记录保存在 `src/locales/overrides.json`，作为修改来源参考；实际构建只读取已合并的 `ui.json`。
