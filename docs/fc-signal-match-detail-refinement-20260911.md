# 比赛详情首版精修

日期：2026-09-11。承接赛程赛果精修，仅调整 `design=kpr5` 的公开比赛详情与相应外层排版。本批是供用户比较的本地首版，未提交或发布，也未视为视觉定稿。

## 设计与交互

- 合并首屏重复的赛事状态，保留一处完整的更新状态及重试。比赛概况使用细黄顶线、双方队徽、大比分、逐图累计走势及原有最佳选手信息；缩短进入第一张地图前的距离。
- 保留连续逐图战报和完整双队统计，默认全部展开。增加统一展开、收起数据，以及章末上一图、下一图；收起后仍能读到本图结果和已记录出场摘要。跳转依据实际记录顺序，不假设地图序号连续。
- 地图索引写明“本图”比分，概况与章节分别写明“每图后的大比分”“本图后大比分”。不改变比赛结果、统计聚合、评分或对位样本规则。
- 常驻“查找选手”直接打开并聚焦现有搜索，把选手工作区放到全队汇总之前。由对位比较进入查找时显示可搜索的全场汇总，保留比较双方；查询、职责、队伍、地图和折叠参数继续共存。
- 1360 px 及以下使用横向地图索引，让窄桌面获得更宽的统计空间。跳转距离按固定页头和两层导航的实际高度计算；手机保留表格内部横向浏览。320 px 下缩短英文导航为 Maps，并调整队名与比分尺度。
