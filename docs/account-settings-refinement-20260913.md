# 账号设置：概览与操作反馈（2026-09-13）

本轮继续账号系统，范围为账号设置及其与我的空间、登录入口的衔接。沿用 FC Signal 的黑、黄、纸白色与公共导航；弃权积分及处罚规则仍停留在讨论状态，本轮没有修改 System 或相关结算实现。

## 页面与行为

- `/account` 默认进入账号概览；保留 `#profile`、`#password`、`#email`、`#sessions` 深链接。
- 概览使用当前登录账号与 `/me/sessions` 的真实响应，展示邮箱验证、有效登录、资料与改密入口。设备读取失败显示“暂未同步”，不会显示为零；其他入口继续可用。
- 个人资料增加展示预览、字段解释和保存栏。仅提交有变化的字段；账号资料与参赛档案、出赛名单明确区分。只读账号保留查看能力。
- 资料和密码表单离开分区、跳转页面时均有草稿保护；刷新与主动退出沿用现有保护。会话失效仍直接生效。确认离开才丢弃本页草稿，回到该分区重新读取已保存资料。
- 密码页提供独立显隐按钮、限制说明与所有设备退出的影响说明，保留服务端改密结果确认。改密提交不会被该表单自己的草稿保护拦截。
- 邮箱页展示发送、打开链接、刷新状态三个步骤，以及已验证、邮件服务不可用和投递结果。发送到投递服务不等同于用户已收信或已验证。
- 设备页区分当前登录与其他登录。退出选定设备、其他所有设备或当前登录均先确认范围；取消及 Escape 不发送退出请求。列表按登录记录计数，同一设备可以有多个记录。
- 采用同一套按钮高度、边框、焦点和反馈样式。手机端五个分区全部可见；资料预览在窄屏移到表单下方。英文文案仅作用于账号设置框架，用户名称与介绍不参与翻译。
