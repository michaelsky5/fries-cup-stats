# 五等分阵容导航与职员分类

日期：2026-09-11。状态：本地实现及验证完成；未提交、推送或部署。

## 实施结果

阵容导航改为五个等宽入口：阵容总览、参赛战队、参赛选手、战队职员、赛事职员。桌面整格可点击，文字左对齐，细竖线分隔，当前项用整格黄色底线标识。窄桌面允许中文与英文代号上下排列；手机隐藏辅助英文，每项至少 100px，在导航内部横向滑动，当前项在进入栏目和调整宽度时保持可见。键盘焦点使用独立轮廓。

两类职员沿用选手目录建立的共同框架：纸色名单、墨黑预览、相同的标题层级、搜索、分页及手机展开操作。

- 战队职员：全部、经理、教练三个标签，保留所属队伍筛选。预览显示公开头像或队徽、所属队伍和报名记录，通向队伍档案。
- 赛事职员：全部、赛管、解说三个标签。职务名称按用户确认统一为赛管与解说，英文为 Officials 和 Casters；取消不适用的队伍筛选与队伍排序。预览保留比赛署名、阶段和有条件可用的回顾入口。
- 阵容总览对应拆出两张职员入口卡，分别使用两类记录数量。桌面四列、窄桌面两列、手机单列。
- 页签标题、栏目标题、搜索提示、空结果和数据来源说明与分类一致。计数仍是档案或署名记录数，不改写为去重人数。

新版使用 `/staff?group=team` 和 `/staff?group=event`。旧链接按 `type`／`role`、选中档案、队伍筛选推断所属类别；没有这些条件时默认赛事职员。类别写入 URL 后，清空筛选仍留在同一类。显式类别优先于旧条件，不适用的筛选、分页和选中项会清理。栏目切换从完整名单开始，保留赛事及语言；返回档案来源时恢复完整目录地址。原版保留综合职员名单。
