# 我的空间沿用当前赛事

本次确认的行为：右上角已选择的赛事也是进入“我的空间”的默认赛事，进入后无需再次选择。

- 默认入口优先使用当前公开赛事，并通过账号返回的参赛赛事列表核对身份；上次参赛赛事不会覆盖当前选择。
- 明确包含 `competition` 的赛事、队伍或比赛链接继续打开指定目标，并保留原有权限检查。
- 当前赛事没有账号的参赛关系时，说明尚未关联身份，不自动进入另一项已参加的赛事。
- 在“我的空间”主动切换参赛赛事时，已在公开目录中的赛事同步更新右上角选择；未公开赛事继续使用账号入口。
- 切换赛事清除上一赛事的队伍、周期、表单步骤和任务参数，保留语言与界面设置。

实现只调整前端默认选择和导航，不改变账号身份、赛事权限或业务数据。验证分别覆盖导航模型与本地示例账号浏览器；正式发布另行验收。
