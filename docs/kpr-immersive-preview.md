# 人物镜头第四版

本地入口：<http://127.0.0.1:4187/?season=FCR26&design=kpr4>

第四版把归档赛季首页处理成一段可操作的冠军故事。页面先建立 AIP 的冠军场景，再由滚动或章节按钮转入单名选手镜头；五名代表选手可以直接切换，人物、英雄、职责、指标、档案入口和无障碍播报同步更新。比赛征程仍保留在首屏故事之后，让视觉叙事最终回到真实比赛数据。

## 设计判断

[KPR](https://kprverse.com/) 的吸引力并不只来自高质量角色图。它把加载、导航、滚动、光标反馈和微型标记都写成同一种世界语言，使访问者感觉自己进入并控制一个系统。其核心可转译为四条原则：

- 每一幕只设一个绝对主角，其他信息围绕主角建立层级。
- 巨型标题与极小系统标签并置，产生尺度和空间感。
- 滚动改变场景构图与信息关系，而不只是让页面继续向下。
- 点击必须立即给出可见反馈，并保持人物、数据与去向一致。

本版使用薯条杯黄、黑、白和 FryDeck Overlay 的信息框架实现这些原则。它没有复制 KPR 的美术、代码、字体、视频、音频或品牌图形，也没有尝试把网页伪装成 KPR 的复刻版。

## 数据与荣誉规则

- 冠军、决赛比分、队伍与选手入口、职责指标及最后三场比赛均来自现有 FCR2026 数据。
- 选手代表按各职责赛季出场时间选取，不代表决赛首发或决赛选角。
- 2026-09-01 经赛事组织方确认，FCR2026 官方 FMVP 为小狗帅哥；该荣誉写入独立配置，不由评分或统计榜首推定。
- 展示英雄采用冠军队伍确认的选择：Muya–猎空、Dani–索杰恩、EVER–西格玛、璐璐–雾子、小狗帅哥–飞天猫。它们只控制典藏人物主图，不覆盖赛季常用英雄统计，也不代表决赛首发或决赛选角。
- 第二幕默认进入小狗帅哥的正式 FMVP 镜头，其余四名冠军选手仍可自由切换为普通人物镜头。

## 素材

- 人物主图与阵容缩略图复用现有 FryDeck 英雄抠图。
- Paper 001 纸纹来自 ambientCG，许可证为 CC0；来源、原始 ZIP 条目和 SHA-256 见 [`public/design/kpr-archive/ASSETS.md`](../public/design/kpr-archive/ASSETS.md)。
- 标题字体为 Barlow Condensed Black，许可证为 SIL OFL 1.1，仅在第四版内使用。
- 界面继续使用 HarmonyOS Sans，并在页面底部提供许可证入口。
- 本版未加入官网宣传片、原画作者作品、电竞工作室案例、拆包模型或 KPR 站点素材。

完整的使用边界见 [`docs/design-material-policy.md`](./design-material-policy.md)。

## 实现范围

- `KprImmersiveArchive.jsx`：真实数据映射、章节状态、选手联动和链接。
- `KprImmersiveArchive.module.css`：冠军与选手两个场景、响应式布局和低动态模式。
- `design=kpr4` 只在归档赛季首页启用；旧预览和无参数默认页面保持隔离。
- 这是 React + CSS 的二维深度表达，没有引入 WebGL、背景音乐或新的运行时依赖。

## 验证结果

- ESLint 与 Vite production build 通过。
- 1440 × 900、1280 × 720、390 × 844、320 × 740 均无横向溢出。
- 五名选手、关闭动效、中文与英文界面均通过联动检查。
- 决赛和征程比赛入口均打开真实比赛页面。
- 旧 `kpr`、`kpr3` 选手名切换及默认原版隔离通过。
- 浏览器控制台错误与已加载失败图片均为 0。
