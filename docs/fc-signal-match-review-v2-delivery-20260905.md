## 本轮实际变化

- 阅读顺序改为：紧凑对阵/比分 → 系列赛进程 → 全场或单图的出场选手 → 按需展开的双方总计、职责关键表现 → 录像与赛事信息。
- 比分区压缩面积，解释 FT 赛制，常见决赛轮次使用中文名称。双方身份沿用固定顺序，黄底用于当前选择和获胜标记。
- 地图进程显示累计比分、追平和决胜图。存在缺失地图或未知结果时，后续累计比分显示“—”，不补猜比赛过程。窄屏选图时，进程与范围入口自动把当前项滚入可见区域。
- 默认显示全部实际存在统计的选手，按“队伍＋选手＋职责”汇总。换职责分行，同图多英雄记录只计一次出场；替补和低样本记录仍保留。
- 全场与单图共用一套数据区。范围、姓名搜索、职责、队伍、比较对象和手机指标视图保留在 URL；切换统计范围会清理旧比较对象。
- 支持双方同职责比较。搜索自己的姓名后，可以直接查看对方同职责选手；选好双方后自动定位到比较结果。不同出场图数会提示样本不等。
- 全场评分与本图评分分别标注，沿用对应的已有评分计算；不平均单图分数，不把缺失评分显示为 0。增加评分和样本说明。
- 手机默认使用紧凑选手记录；完整指标可切换为内部横向滚动表，固定选手列。搜索提示色与队伍下拉宽度显式适配当前浅色页面。
- 已完成比赛优先提供本场录像或赛事录像库；真实链接为录像库时仍明确标为录像库。比赛房保留在赛务入口，赛前/进行中状态放到主要操作位置。
- 弃权、未赛等状态保留独立说明；队伍登记阵容与本场实际出场记录明确区分。
- 保留原版详情分支、源列表返回与选手返回状态。清除返回滚动状态后进行筛选，不再因此强制跳回页顶。

原有逐图展开/收起交互由新版的全场/单图切换取代；原版仍保留连续展开交互。旧 `map` 链接仍选择对应地图，只有 `expand=all` 的新版链接显示全场汇总。

## 已知边界与后续

1. 实际浏览期间，公共数据刷新仍出现过失败提示，页面保留此前可用的公开快照。提示条会改变首条记录的纵向位置，因此不把某次首屏坐标当作所有状态的保证。
2. 本轮主要验证归档公共数据。待赛、未知与弃权边界有逻辑回归，真实进行中赛事与账户 → API → 持久化流程仍待专门验收。
3. 选手档案的返回按钮仍固定写“返回选手列表”，实际能恢复比赛筛选。下一批阵容路线统一来源文案，并衔接选手档案携带的 `player` / `role` 参数与比赛中的选手定位。
4. 暂未新增逐帧视频、录像时间戳、官方名单确认或赛务政策。只有赛事已发布的数据和链接参与展示。

## 整站版式判断

继续采用 FC Signal 的字体、网格、黄黑白和状态表达。各类页面使用适合任务的组织方式：

| 页面 | 下一步处理 |
| --- | --- |
| 赛事总览、晋级形势 | 保留主方向，精修状态与跨赛事表现 |
| 赛程精选、完整列表 | 精修密度、筛选、轮次和比赛行 |
| 比赛详情 | 本轮已经重排复盘顺序；根据实际预览继续收口 |
| 阵容门户、队伍/选手/职员目录 | 作为同一页面家族升级，统一导航与查找顺序 |
| 队伍详情 | 重排身份、赛季表现、完整阵容与比赛，整合重复名单 |
| 选手详情、数据排行 | 保留已有档案和主表，深化身份、样本、比较及返回路线 |
| 英雄、地图列表与详情 | 重做索引与详情布局，让筛选、比较和关联比赛成为主体 |
| 我的空间、比赛房 | 按 Control 单独组织任务、状态和操作，并用真实角色流程验收 |

建议顺序保持 B 阵容路线 → C 数据路线 → D 进行中赛事 → E 账户路线 → F 正式替换。账户测试环境可以提前准备。先完成一个页面家族的连续体验，再复制已验证的公共规则。
