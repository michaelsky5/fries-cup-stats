# 选手、队伍、职员目录 · 共同框架本地试版

日期：2026-09-10。状态：本地实现与浏览器复核完成，供视觉审阅；未提交、推送或部署。

## 方向依据

用户选择选手目录作为视觉基准，并确认“相同框架，内容表达各有特点”“既能快速找对象，也愿意停下来浏览”。这确认了本轮方向，尚不代表用户已认可最终视觉。

前三份独立试稿保留历史记录：[选手](fc-signal-player-index-trial-20260910.md)、[职员](fc-signal-staff-credits-trial-20260910.md)、[队伍](fc-signal-team-index-trial-20260910.md)。职员的左右分栏和双列姓名册、队伍的队旗网格和整排展开，被本轮共同框架取代。

## 实现

- 新增 `src/features/roster-directory/RosterDirectory.jsx` 与共用样式：标题、范围标签、搜索、排序、更多筛选、已选条件、名单、分页、选中反馈与空状态统一。
- 桌面沿用选手页的纸色左侧名单、墨黑右侧预览。常规面板高 700–760px，名字与编号使用同一尺度；列表内部滚动。长阵容和长身份信息自然增加内容高度。
- 选手保留已有英雄图构图、真实职责和统计范围；队伍以真实队徽、完整报名阵容、经理与教练、赛季结论及分阶段赛程构成预览；职员以姓名、公开头像或所属队伍、报名及比赛署名构成预览。
- 手机明确选中后在该行下方展开，三页共用收起按钮；收起后焦点回到对应名字。调整 360px 职员姓名字号，避免四字姓名挤成三加一的断行。
- 主入口仍通往原有选手档案、战队展馆、赛季征程和职员回顾。URL 查询、分页、关注、选择和返回滚动语义沿用原实现。
- 新版限定在 `design=kpr5` 分支。数据选择器、发布快照和详情页未由本轮更改。

品牌文档更新为 1.1，实施规范更新为 2.1；共同模板成为后续三个目录的实施基准。
