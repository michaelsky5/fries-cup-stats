# 导演剪辑版：母版与英雄迁移规范

基准：2026-08-31，`2026-08-31-v75`。以卢西奥票面为构图母版，雾子作为“独立元素与背景线分离”的第二个样本。当前目录中的 53 个英雄均已迁移，逐英雄记录见 [v75 迁移清单](director-cut-hero-migration-v75.md)。

适用范围：同一导演剪辑版的其他英雄，以及这些票面的网页预览和分享导出。常规回顾页、其他比例海报可以沿用主次关系，不直接硬套这张横向票面的坐标。

## 核心结论

**统一的是构图、分层和阅读顺序；每个英雄自己的符号与线条语言必须保留。**

这是一张“参赛者主演、英雄出演”的赛季纪念票。第一眼应该是参赛者姓名与英雄人物，随后是自己的赛季记录，最后才是值得细看的英雄符号、线条和票务细节。

“帅”来自人物尺度、轮廓、方向感和可识别的英雄符号；精致感来自清晰的主次、节制的颜色、留白和对齐。不要用增加发光、碎线、小刻度来代替构图，也不要把背景淡到失去英雄气质。

## 固定骨架与可变内容

| 区域 | 必须保持 | 每个英雄可以改变 |
| --- | --- | --- |
| 票面骨架 | 黑色主票、黄色边轨、奶油色副券、切角、检票缺口、数据栏与分隔节奏 | 不随英雄重做结构 |
| 左侧人物 | 主视觉位置、清楚的面部、干净的下缘过渡 | 按素材调整尺度、裁切、重心及少量轮廓色 |
| 人物后方线条 | 属于背景层，左侧可见，进入文字区后衰减 | 弧度、间距、断续、方向、少量英雄色 |
| 右上独立 SVG | 一个清晰主符号，与文字、背景线分离 | 符号形态及小范围的光学校正 |
| 中部姓名与信息 | 参赛者优先，ID 和真实数据清楚 | 内容长度适配，不为装饰改写数据 |
| 右下英雄英文名 | 完整、右对齐、低对比，作为版本署名 | 按字长与名单长度自动适配大小 |

## 三个装饰层各司其职

### 1. 背景线：让人物处于自己的氛围中

- 重点在人物后方，而不是只从姓名拉一根线连到右上 SVG。
- 可以延伸到 ID 后方，但必须画在文字下面，并在文字区明显减弱；不能切过面部成为前景线。
- 一组线只表达一个主要运动规律。线的数量不是统一指标：卢西奥适合成组音波，索杰恩适合少量方向明确的轨迹。
- 通过粗细、明暗和疏密形成主线与陪衬线，不让每根线同样抢眼。
- 卢西奥保留短周期的绿金音波：人物后方能看见，向右逐渐消失，不再向唱片符号强行汇聚。

### 2. 独立 SVG：让人认得英雄，不承担整张票的背景

- SVG 自身保持完整、清晰、克制。不要把导航箭头、长路径、轨道和装饰尾线都塞进同一个符号。
- 雾子的鸟居只保留鸟居本身；不让额外箭头穿进门内。卢西奥符号本身的双向切换箭头则属于语义，不应一律删除。
- 优先借鉴官方技能图标的轮廓概括、负形与辨识度；需要重新确定某个英雄的符号时，再核对该英雄的官方资料，而非凭空堆几何形。
- 允许在既定右上区域内按形状微调。细长武器、圆形符号、鸟居不必用完全相同的宽高，但视觉重量应接近。
- “线与 SVG 分离”指职责、位置和绘制控制分离，不是禁止 SVG 使用线条。背景本身也可以用矢量路径绘制。

### 3. 英文英雄名：完整的版本署名

- 不再藏在英雄脑后，不与参赛者姓名形成第二个大标题。
- 保持右下区域、右对齐；字母、空格、重音、标点完整保留，例如 `LÚCIO`、`SOLDIER: 76`。
- 先测量演职员名单实际宽度，再为英雄名留安全间距。不能只用某个短名字的截图决定所有英雄的宽度。
- 普通名称保持母版位置；较长名称缩小；特别长的名单触发下方紧凑署名，名单不因此删减，英雄名也不裁切。
- 本次只轻提轮廓对比；小字号同时减细描边，避免变成粗重的小标签。

## 实现边界与当前进度

截至本版，目录中 **53 个英雄均使用人物后方背景线、右上独立 SVG、右下完整英文署名**。票面骨架、人物素材校准、中部数据栏、副券和真实数据映射保持不变。

- 卢西奥、雾子保留已确认的 `soundwave`、`fold` 背景；其余 **51 个**各有一套独立路径，统一接入 `lineLayer: 'ambient'`，不再走旧的前景线编排。共用的是衰减和绘制顺序，几何形状各自设计。
- 本轮清理了 **45 个 SVG 源文件**的旧引线、路径节点或无关箭头；已经干净的 8 个源图不为追求修改数量重画。
- **50 个符号**使用按实际形状校准的独立裁取范围，保留原始宽高比，不再把整体边缘渐隐到残缺。卢西奥、雾子、索杰恩保留已确认的图形取景与处理方式。
- SVG 位置由 `heroEmblemX/Y` 独立控制，背景路径不再借用其焦点。调整背景线不会顺带移动图标。
- 英雄名继续使用统一的 `getDirectorCutFooterLayout` 与 `drawDirectorCutFooterWordmark`，不另写 53 套署名布局。
- `stageAuditVersion` 只是缓存与配置版本；实际检查证据记录在迁移清单中。

| 文件 / 函数 | 职责 |
| --- | --- |
| `src/lib/directorCutProfiles.js` | 汇总英雄色、人物校准、背景、SVG 取景和署名配置 |
| `src/lib/directorCutAmbientFields.js` | 53 个英雄的背景意图、路径与强度；51 套路径使用独立的 1000 × 600 坐标场 |
| `src/lib/directorCutEmblemFrames.js` | SVG 源图范围、视觉尺寸及 `heroEmblemX/Y`，不引用背景焦点 |
| `src/lib/directorCutLineDirections.js` | 保留旧构思、运动规律和兼容配置；不再控制新背景或独立 SVG 的最终位置 |
| `public/review/hero-marks/*.svg` | 每个英雄独立符号的源图 |
| `drawDirectorCutAmbientLineField` | 人物后方的氛围线，以及进入信息区后的衰减 |
| `drawDirectorCutHeroEmblem` | 右上独立符号的裁取、尺寸、位置与明暗 |
| `getDirectorCutFooterLayout` | 一次测量名单和英雄名，统一处理防碰撞与长名称 |
| `drawLandscapeDirectorCutTicket` | 共用票面结构和绘制顺序，不复制成 53 套页面代码 |

注意三个技术边界：

1. 背景支持 `soundwave`、`fold` 和 `authored`。新增英雄必须同时补齐背景目录和符号取景目录，不能只切换 `lineLayer` 开关。自动回归检查目录完整性及路径签名，防止漏项与整套几何复制。
2. `authored` 路径在人物后方绘制，通常 3–5 条，保持一组主要运动规律。先调几何，再调强度；不要在 SVG 源图里重新补一根连接到人物的长线。
3. 独立源图的裁取范围基于 360 × 260 的 SVG viewBox；绘制时等比容纳。偏长的枪、剑、弓不应拉伸成方形，也不应为了统一宽度把顶部裁掉。

### 母版的定位基准

以下坐标属于内部 **1600 × 760** 票面，不是最终 1920 × 1080 图片：

- 主副券分界 `x = 1322`；主内容左缘 `x = 630`；内容宽度 `662`。
- 英雄署名右缘 `x = 1288`，常规基线 `y = 650`，最大宽度 `392`。
- 英雄署名与名单至少留 `28` 的横向间距；常规适配下限字号 `32`。
- 空间不足时，署名使用 `y = 662` 的紧凑基线、最大字号 `28`，仍然完整显示。
- 网页预览与导出复用同一渲染函数；改变浏览器窗口不应产生另一套构图。

## 后续英雄如何沿用

每个英雄先写一句“背景表达什么，独立符号是什么”，再动代码。以下是本轮已落地的代表，完整 53 项见迁移清单：

| 英雄 | 人物后方的线 | 右上独立元素 |
| --- | --- | --- |
| 卢西奥 | 绿金、成组、短周期音波 | 保留当前唱片 / 切换符号 |
| 雾子 | 少量轻盈折线或流动弧线，保留间断 | 干净鸟居，不穿插额外箭头 |
| 黑百合 | 少量绷紧的瞄准线与优雅弧度，不铺满蛛网 | 保留可辨认的蜘蛛主形 |
| 西格玛 | 有弯折与失重感的弧线，不叠成同心圆仪表盘 | 独立的引力主题符号 |
| 生命之梭 | 从秩序向舒展生长过渡的线，不做满屏藤蔓 | 独立花瓣 / 生命主题符号 |
| 索杰恩 | 少量有方向的轨迹，人物后方可见，文字区克制 | 保留当前干净的武器剪影 |

以后扩充或重修时，可按 **12–18 个英雄**组织一批。共用的是绘制方法和衰减规则，不能用统一模板替代每张的符号辨识度与小图检查。

每批的执行顺序：

1. 保留现有票面结构，检查素材、旧 SVG 与线条配置。
2. 清理符号内无关路径，确认符号在没有背景线时也成立。
3. 实现该类背景线，移到人物后方，再控制进入信息区的衰减。
4. 调人物重心与符号视觉重量；不要为填空继续添加装饰。
5. 用共用布局检查短名、长名、长名单及 ID，再核对网页和导出。
6. 记录“改了什么、实际看过哪些图、还有什么未通过”，不以版本号代替验收。

## 验收门槛

- 原尺寸 1920 × 1080：面部无前景杂线，SVG 不残缺，英雄名完整、不压名单，字段含义和数据不变。
- 约 480 × 270 分享尺寸：仍能先辨认人物与参赛者；允许装饰性微字退为纹理，但不能要求放大后才认得主符号。
- 至少包含卢西奥、雾子、一个长英文名、一个低明度配色，以及长 ID / 长名单用例。
- 浏览器确认图片 `complete && naturalWidth > 0 && naturalHeight > 0`，并检查页面报错；不能仅看 `<img>` 是否存在。
- 运行 `npm run test:review-season` 及修改文件的 ESLint；测试验证数据和布局约束，不能代替每张票面的视觉验收。
