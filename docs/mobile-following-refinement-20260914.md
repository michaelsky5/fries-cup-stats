# 手机我的关注精修记录

日期：2026-09-14

## 本轮范围

针对「手机像桌面缩小版、重点不清楚」继续整理 `/me?section=following`，覆盖游客页面与账号内复用的 FollowingWorkspace。本轮保持 FC Signal 的纸色、墨色、黄色和直角控件，不修改关注存储协议、赛事数据或评分模型。

- 700px 及以下压缩页头，数量直接呈现，添加与管理保留。正常保存状态和登录入口移到页尾；同步失败仍优先提示。桌面保留配额和同步状态。
- 无关注时直接出现发现面板，不再提供重复的“发现关注”按钮。手机减少重复标题说明，搜索和可关注对象提前。
- 关注近况保留一场重点比赛，队徽、队名和比分直接可见；其他比赛改为手机横行。RR5 五个位置、当前比分和缺失地图继续完整展示。
- 没有未读变化时，详细查看记录说明按需展开；真实变化、旧快照提醒和保存失败继续显式呈现。
- 手机目录按队伍／选手切换；默认选择有内容的类别。`followCollection` 独立于对象和比赛状态筛选，随返回链接保留。桌面继续显示两类目录。
- 修复“查看相关比赛”切换列表后仍停留在下方的问题，使用提交后的 DOM 聚焦和定位；完成发现选择后也回到当前近况或比赛视图。
- 已归档关注列表使用“关注比赛记录”，区别于赛事回顾产品；人物卡明确标注登记职责，避免与其实际出场职责混淆。英文关注数量使用单复数。
