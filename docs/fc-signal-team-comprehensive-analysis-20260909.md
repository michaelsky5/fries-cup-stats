# 队伍竞技分析：综合表现改版

日期：2026-09-09。状态：本地实现与验证完成，未提交或发布。

## 页面职责

保留「队伍展厅 / 赛季征程 / 竞技分析」三个入口。竞技分析从地图主导改为综合表现阅读：先给观众整体战绩和三个可核对的观察，再让选手、教练和经理展开成员、阵容、对手及具体比赛的证据。

页面顺序为整体表现、团队战斗、成员表现、英雄与阵容、阶段变化、对手研究、地图与模式。采用 FC Signal 的纸色、墨黑、黄色和清晰刻度；数值、参照和样本量放在一起，复杂证据按需展开。

## 内容与交互

- 全页赛段筛选同时作用于战绩、团队指标、赛事参照、成员、英雄、禁用、趋势、对手与地图。
- 团队伤害、消灭、死亡、治疗、减伤、助攻可在「相对赛事 / 同场双方 / 赢图与输图」之间切换。
- 成员保留完整注册名单以及比赛记录中的历史成员，按职责阅读；选择成员后比较同场同职责对手的时间加权人均数据。展厅与分析共用成员选择。
- 英雄按职责呈现最终记录，提供全部英雄索引、完整五英雄组合和双方具名禁用记录；证据可进入对应地图。
- 趋势同时展示本队与当场对手，配备精确数值列表和赛段汇总；缺失样本不连线。
- 对手研究包含实际交手战绩、六项同场指标、再次相遇的逐场变化和完整地图证据。
- 地图章节保留原有地图索引与散点图，并补充各模式的胜图数、样本数和胜率。
- 筛选与展开状态保存在 URL；比赛证据指向具体地图，返回后恢复队伍、对手、证据和阅读位置。跨队伍分析链接保留当前赛段。

## 数据口径

团队指标由有效比赛地图记录重算，不依赖当前名单累计值。判罚、轮空、取消、未完成及不符合档案条件的地图不作为已打出的竞技证据。

完整团队样本要求五名不同且可识别的选手，以及各自有效的出场时间。团队每 10 分钟指标使用总记录值除以「五人出场时间之和 / 5」再乘 10。仅当个人时间为空时回退到地图时长；明确为零或无效的个人时间不回退。缺失指标按项排除，真实零值保留。

同场比较只使用双方该指标都完整的同一批地图。赛事中位数按当前赛段可用队伍等权计算，并显示各队样本。成员比较使用同图、同职责、完整对方名单中的对手选手，以出场时间加权计算人均值。赢图 / 输图比较不包括平局，整体地图胜率保留平局分母。

消灭数是个人消灭记录之和，同一目标可能重复计数。最终英雄记录不代表整图使用时间；五人共同出场不宣称官方首发。禁用仅统计具名已发布记录，缺失不表示没有禁用。没有团战、首杀、大招事件时间线，不推断这些指标或战术因果，也不引入新的综合评分。
