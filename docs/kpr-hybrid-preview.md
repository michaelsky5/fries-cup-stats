# 冠军群像与人物镜头融合版

本地入口：<http://127.0.0.1:4187/?season=FCR26&design=kpr5>

第五版把第二版的冠军群像与第四版的人物镜头连成同一条赛季叙事。首屏先展示五名冠军选手，点击任一人物进入对应镜头；直接滚动进入第二幕时，默认聚焦官方 FMVP 小狗帅哥。首屏之后按“赛季索引 → 夺冠路径 → 冠军人物与数据”展开，避免赛事总览只有冠军海报而缺少继续探索的入口。

## FCR2026 展示配置

- 官方 FMVP：小狗帅哥。来源为赛事组织方在 2026-09-01 的确认，不由评分或榜首推定。
- 群像顺序：Muya–猎空、Dani–索杰恩、EVER–西格玛、璐璐–雾子、小狗帅哥–飞天猫。
- 职责构图：两名输出在左，重装固定居中，两名支援在右。
- 展示英雄是冠军队伍确认的人物呈现选择。`most_played_hero` 及职责指标仍保留原赛季数据；展示选择不代表总决赛首发或选角。

## 内容结构

1. 冠军群像：队伍、五人、决赛比分与人物镜头入口。
2. 人物镜头：默认 FMVP，五名选手均可切换，人物、英雄、职责、赛季数据和档案链接同步更新。
3. 赛季索引：晋级结构、完整赛程、队伍与选手、地图与排行榜四个入口。
4. 夺冠路径：冠军最后三场已完成比赛，直接连接真实比赛档案。
5. 人物与数据：冠军阵容、展示英雄、赛季 OVR 与选手档案。
