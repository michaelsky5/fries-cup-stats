# FC Signal · 地图数据页精修

日期：2026-09-12。范围：本地 `design=kpr5` 地图索引、地图档案，以及相关来源返回。未发布。

## 这轮调整

- 延续选手与英雄页的紧凑赛事状态、分区导航与短标题。实际已收录模式组成等宽入口；FCR2026 为六栏，手机为三列两行。数量写明“条记录”。
- 搜索和排序独立成行，支持中英文地图名称及中文输入法组合输入。结果区说明筛选数量、清除操作和全季占比分母。
- 实景缩略图与桌面预览继续承担地图识别。预览改用墨黑、纸白、黄色主要入口；记录数排名始终使用全季记录数名次。
- 档案首屏使用地图名称、实景和已发布地图记录数。模式内占比与全赛季占比各带分子、分母；平均时长显示有效时长样本数。
- 地图档案的英雄视图、职责、阵容选择、队伍排序与展开、比赛筛选和展开状态进入 URL。来源返回保持目录条件与阅读位置，页内章节跳转也保留来源。
- 地图与英雄档案互通；从地图进入比赛、队伍或选手后，相关页面识别地图来源。数据分区导航与来源返回分别处理，避免“地图数据”导航指向英雄。
- 沿用既有素材和统计模型，没有修改赛果、英雄计数或评分逻辑。
