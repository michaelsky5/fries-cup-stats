## 已交付

| 范围 | 现在的行为 |
| --- | --- |
| 导航与列表返回 | 普通跨页链接继承设计、语言和目标赛事；列表筛选只在明确需要时保留。返回精选清除列表参数并回到顶部；详情返回恢复原筛选和阅读位置。 |
| 手机菜单 | 点击导航、切换路由、点外部或按 Escape 后关闭；Escape 将焦点还给菜单入口。 |
| 跨赛事与独立体验 | 从实体详情切换赛事回到对应目录，避免带入另一赛事的实体 ID；我的空间、阵容子导航、回顾及电竞经理保留全站上下文。 |
| 数据读取和更新 | 优先使用已发布数据；缓存只保存有效的已发布快照。首次远端失败可使用明确标识的本地备用数据；后续刷新失败保留上次记录，显示失败和重试入口。 |
| 数据稳定性 | 拒绝时间更早的已发布快照；数据未变时保留对象，避免后台刷新重置页面状态。备用数据不能凭本地时间覆盖权威发布。响应正文也受超时限制。 |
| 状态与时间 | 赛事生命周期与数据来源分开显示；不再借“是否有回顾”判断归档。同步动画只在请求期间出现，手机可读实际更新时间。移除加载时虚构的队伍和选手数量。 |
| 数据表达 | 地图全站占比使用全部有效地图作分母；签表与比赛详情统一读取 FT/BO，缺少依据时显示未知。QGCS4 决赛及季军赛均为 FT4。 |
| 跨赛制 | QGCS4 按实际数据显示小组赛 36、季后赛 8、合计 44；不展示不存在的瑞士轮与突围入口。单败使用对应淘汰说明。异步冠军更新不再被旧翻译占位文本覆盖。 |
| 比赛房与错误恢复 | 区分身份检查、未登录、账户服务不可用、无权限、房间未开放和读取失败；提供实际登录弹窗、重试和确定的比赛返回目标。正式 404 与路由异常页提供可继续入口及标题焦点。 |
