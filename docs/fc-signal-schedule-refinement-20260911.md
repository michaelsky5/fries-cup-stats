# 赛事精选与队伍查找精修

日期：2026-09-11。承接[首批赛程整理](fc-signal-schedule-polish-20260911.md)，范围为 `design=kpr5` 的归档精选、列表队伍搜索和手机阅读层级。本批为本地预览，未提交或发布。

## 设计与数据约定

- 页面形成一张重点对阵主卡、两张有明确看点的精选卡、其余紧凑赛果行，共最多八场。沿用黑、纸白、薯条黄、队徽及比分的视觉体系。主卡强调实际胜方；手机缩短说明，收起查找区重复的完整赛程按钮。
- FCR2026 保留 REG–AIP 总决赛，补入瑞士轮 DXG–NOT 和突围赛 ECNU–BANANA。两场的实际比分过程分别是 NOT 从 0:1 到 2:1、ECNU 从 0:2 到 3:2，均可打开对应比赛核对逐图结果。其余场次按紧凑记录扫描。
- 显式精选配置优先保留首场及指定集合；自动补充时从有记录的其他阶段选择，避免全部集中于季后赛。已完成、非轮空才可入选，自动补充排除判罚与弃权；显式选入的判罚记录仍使用判罚说明。
- 比分叙事要求完整且一致的地图证据，包括已知赛制、地图胜方、累计图胜及系列赛分数。缺分、缺图、矛盾结果、判罚或胜负已定后继续出现地图，都退回普通记录。平局不增加图胜；“打满 N 图”需要相应赛制和实际图数支持。没有地图证据的卡片使用“已发布比赛记录”入口说明。
- 两个页面共用队伍候选，展示真实队徽、简称、全称和本届赛程条数。按身份去重，简称/全称的唯一精确匹配可直接回车选择；点击或方向键选择后携带 `teamId`。模糊查询继续可用，同名多身份不自动代选。列表更换队伍保留阶段等条件，重新输入清除旧身份。
- 保留中文输入法组合态保护，提供组合框、列表选项、方向键、回车、Esc、焦点离开关闭及可见焦点。候选的场次包括公开弃权记录，含义为赛程条数，不代表实际出场次数。
