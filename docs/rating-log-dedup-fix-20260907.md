# 学院赛重复统计修复 · 2026-09-07

已完成本地代码修复和验证，尚未部署或重新发布赛事数据。原始公开快照保持不变。

## 修复内容

学院赛 V5 把同一场、同一地图、同一选手的历史导入记录和当前记录重复合并。旧代码将导入 ID 当作比赛身份的一部分，导致重复记录进入英雄评分基线、累计数据和样本资格计算。

- Stats 以正式比赛 ID 为主，结合地图、队伍、英雄、职责、时长及统计值识别重复副本。保留统计冲突、不同英雄片段及身份缺失的记录；仅有导入 ID 时保留来源和阶段范围。
- 发现重复的选手，其职责累计数据从保留的记录重算，地图数、时长、六项指标和 OVR 使用一致的样本。没有重复的已发布汇总仍按原逻辑读取。
- System 的服务端发布器和手动导出器共用修复后的去重及地图身份规则，避免后续发布再次生成这类重复和虚增的累计数据。
- 评分权重、赛季 v1.4 规则、对手强度校正及 FCR26 冻结基线没有调整。

例如“再见”的 DPS 记录由 32 图、383.38 分钟修正为 18 图、220.53 分钟，伤害累计由 420,967 修正为 237,043，正式 OVR 由 85 调整为 80。“普希希”的重装记录恢复为 6 图、47.38 分钟，页面正确显示暂定评分 61，退出正式排名。

这里的 194 个条目按“选手 × 职责”计数，不等于选手人数。旧只读分析中的 OVR 变化仅比较了日志去重；本次结果还包含累计数据、正式资格及同职责分位的完整修正。
