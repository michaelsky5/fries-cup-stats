# 周赛网页报名候选验收 · 2026-09-14

本机候选已打通资格资料、选手本人确认、赛管审核、周期登记、当周参赛确认和周名单提交／锁定。正式环境尚未部署本轮修改，也没有开放正式报名。

## 本轮实现

- 资格申请补充赛区、队伍历史表现，以及可选的队标链接、教练和联系资料。各位置当前段位允许填写“未定级”，历史表现可填“无”，没有强制截图。
- 选手本人填写中国（含港澳台）／其他地区分组、OWCS 2026 经历、三位置段位并确认规则；队长不能代填成员声明。队长和审核员能查看本队资格资料，普通成员只获得自己的资格声明。
- 周赛申请提交和审核均校验 5–7 人、本人确认和资格资料。OWCS 2026 正赛大名单经历不通过；KR／JP 报名名单至少包含两名中国（含港澳台）选手。
- 审核通过后，“我的空间”出现周期登记入口和待办。登记完成后继续确认本周参赛、选择名单；保存草稿、正式提交、等待赛管锁定分别显示状态和下一步。
- 周赛默认采用 `PREVIOUS_APPEARANCE`：与最近一次实际参赛的正式周名单至少保留三人；首次参赛没有固定核心步骤。正常休赛、未开打的弃权不替换基准，也不清积分。中途弃权但已有实际地图记录的周次会成为基准。
- 历史实际参赛缺少正式名单时停止提交并提示核对；同一周一名选手不能进入不同队伍已提交／锁定的名单。显式 `FIXED_CORE` 老周期继续兼容。
- 周期登记、参赛确认和名单写入在事务中重读账号与队伍权限，拒绝过期会话、已撤销经理身份、已归档赛季和关闭窗口；重复登记返回已有登记结果。
- 报名与周名单页面保持现有黑、黄、纸白视觉体系，补齐中／英／韩／繁体文案；移除固定核心步骤后，步骤栏改为按实际步骤平分宽度。

## 正式使用前仍需完成

1. 在测试服务器部署配套前后端，先应用 System `prisma/compat/20260914_weekly_registration_details.sql` 的两个可空 JSONB 字段，再启动新后端；保留原版本和数据库备份。回退应用时可保留这两个附加字段。
2. 配置实际赛季、周次、报名／确认截止时间、邀请名单与能力开关。在测试服务器用真实获邀用户完整验收，再发布正式账号入口和官网报名链接。本轮没有扩大真实邮件收件范围。
3. 审核后的新增选手和换队需要管理员维护；队伍低于三人延续门槛时，本轮会阻止提交并要求赛管处理，尚未提供自助“重建队伍／重新审核”流程。
4. KR／JP 每张地图首发至少两名中国（含港澳台）选手，以及 OWCS 经历的真实性，仍需赛管核验。本轮只自动校验报名声明和报名名单人数，没有宣称已自动审查每张地图的实际首发资格。

本轮提供的是可审查、可继续联调的报名候选。测试环境部署、正式开关、真实账号与邮件验收是独立的上线环节。
