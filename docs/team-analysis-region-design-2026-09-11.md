# 竞技分析：英雄与阵容区域重排

本轮针对“滚动到区域中段，仍然很难分清内容”的问题，调整英雄、阵容、禁用及比赛明细的空间层级。保留六个分析栏目和黑、纸白、黄色的品牌体系。

## 区域设计

- 顶部操作带集中成员、英雄与记录类型。选中英雄后回到操作带，保留切换入口；筛选继续通过 URL 保存。
- 英雄记录使用开放的职责排行，强调姓名、频次和横向比较。
- 阵容区使用整块纸白底与粗顶线。每组以五个英雄为中心，按实际职责分组，左侧为完整记录样本，右侧为胜负、常见地图和比赛入口；去掉每组和头像内部的多层框。
- 禁用区从标题到表格保持深色，双方各占一列。覆盖图数随列标题展示，黄色用于当前排序、展开状态和键盘焦点。
- 展开的比赛作为浅色明细嵌入所属区域，以时间标记串起记录，保留成员、最终英雄、双方禁用及对应地图的比赛链接。
