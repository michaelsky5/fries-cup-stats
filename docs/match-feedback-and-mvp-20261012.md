# 比赛详情数据反馈与 MVP 缺参照说明

比赛详情顶部增加“数据错误反馈”。表单可选择整场或指定地图，以及比分、选手统计、出场与英雄、评分与 MVP、比赛信息等错误类型。反馈正文自动附上公开比赛编号、公开与原始比赛 ID、地图和只含比赛、赛季、地图的页面路径。

提交路径为 `/api/platform/me/feedback`。账号改版后的正式服务没有注册旧反馈路由，因此本次同步补充 System 的独立比赛数据反馈表、个人反馈接口和管理员处理队列。提交使用普通账号的 HttpOnly 会话，由服务器确定提交人；处理沿用当前全局管理员权限。未登录时允许先填写，登录返回时保留弹窗内的草稿。关闭或刷新页面不承诺保存草稿。

提交期间阻止重复点击和关闭。每次独立反馈生成提交标识，重试保留同一标识，服务端按账号和标识保证只创建一条记录。收到匹配本次提交的服务端记录后才显示成功和反馈编号。网络中断、超时、5xx 或异常响应时锁定原草稿，提供只读“核对提交结果”，不会自动重发写入。弹窗还可读取自己的本场反馈与处理说明。

SPS 对 FF（公开编号 FCW26-C01-W04-REG-M05，公开 ID FCW26-SWISS-R1-M12）的最新公开记录包含 50 条选手地图记录。日期为 2026-10-10，当前模型按日期将其归为 `calendar:season5`，此前同组记录数为 0，因此 50 条记录均无评分，统计 MVP 为空。版本分组是推定信息。后续日期的数据不回填这场的评分。

已完成且没有 MVP 的比赛现在显示简短、可展开的原因，区分缺参照、缺选手记录和出场门槛。已有评分与 MVP 的比赛继续显示原卡片。本次不调整评分公式、十分制刻度、MVP 排序或赛季 OVR。
