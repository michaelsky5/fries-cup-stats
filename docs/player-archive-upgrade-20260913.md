# 选手档案与赛季征程升级

日期：2026-09-13。状态：本地实现与验证，未发布。

## 页面分工

选手详情采用与队伍详情相同的档案思路，分为三个连续入口：

| 页面 | 路径 | 阅读重点 |
| --- | --- | --- |
| 选手档案 | `/players/:playerId` | 身份、队伍、已公布荣誉、英雄选择、并肩队友、赛季片段 |
| 赛季征程 | `/players/:playerId/journey` | 个人实际出场，按赛事阶段与日期展开至单图 |
| 竞技分析 | `/players/:playerId/analysis` | 既有职责评分、指标、英雄使用、地图表现、比赛数据 |

共用三等分页签、纸色与墨色、黄色标记和直角控件。档案页的名字、所属队伍、荣誉及实际出场规模先于英雄图出现；手机将内容改为纵向阅读。新档案样式与原分析页的全局元素重置分离，避免标题、间距和卡片颜色被覆盖。

英雄只从该选手的公开出场中选择。默认展示出场图数最多的英雄，可切换主视觉；图鉴先呈现最多四位，其他英雄用可展开的紧凑列表保留。单英雄使用横幅。没有出场的登记选手使用队徽与明确说明。

## 内容与数据边界

- 并肩队友按同队、同一张已发布地图的实际记录计算。同一地图换英雄或换职责只计一次；按共同地图数、比赛数排序。不能把未出场的名单成员当作同场队友。
- 队友身份只使用明确选手 ID 或唯一完整 BattleTag；同昵称不合并。无法对应本届选手档案时保留记录，不生成失效档案链接。无英雄记录的队友使用名字缩写。
- 赛季片段提供首次收录出场、单场出场图数最多、最近一次出场。对应同一场时合并，单场选手只展示一个片段。日期未知时不制造首次或末次时间。
- 征程沿实际出现的阶段组织；学院赛保留瑞士轮、突围赛与季后赛，全高杯按自身小组赛与季后赛展开。阶段英雄数量来自本阶段；链接明确进入全季英雄分析。
- 多职责比赛、地图去重后保留各职责原有单图评分，不生成跨职责平均分。缺失评分与比分保留 `—`，已公布的 0 分保留 0。单图评分维持满分 10 分，不与赛季 OVR 混合。
- 个人征程只计有个人记录的已发布非行政地图；轮空、判罚及未出场比赛不自动成为个人经历。荣誉沿用既有官方记录，不自动推断 MVP、冠军选手或逆转故事。

## 操作与回程

- 档案、征程、分析保留赛季、语言、设计兼容参数和各自视图状态。
- 赛季片段通过 `jmatch` 直达并展开比赛，清除不兼容的阶段筛选；征程阶段使用 `pstage`，展示英雄使用 `chero`。
- 逐图链接进入对应比赛的 `map`，离开时保存来源与阅读位置。返回征程保留展开比赛。
- 从征程进入个人比赛数据时传入完整的职责记录键。分析页自动包含被选中的较早比赛，避免初始八场限制隐藏直达目标，并定位展开行。
- 没有本职责出场时，分析页收束为一条说明及回档案入口，不叠加空图表和空榜单。

## 手机分享预览

分享卡预览按容器的实际宽高等比缩放，手机不再被固定 736px 预览框裁切。手机控件改为纵向排列，使用直角按钮。弹层保留 Escape 关闭、Tab 循环与关闭后焦点恢复，打开时锁定背景滚动。

预览与导出仍使用同一张选手卡；独立导出画布保留 1600 × 900。本轮验证预览与 DOM 中的画布尺寸，未重新执行 PNG 导出及其他账号流程。
