## V4 大厅

- 手机压缩标题、发布入口、浏览切换及探索说明。390×844 预览中，首张卡片由约 958px 提前至约 535px，首屏可见姓名和职责。
- 封面由 186px 缩至 132px，职责文字与英雄分别占据左右区域；姓名和资料向上提。品牌标记加黑底以保证原色英雄上的可读性。
- 卡片共用行网格，长名字自然换行后，同排岗位、段位和资料行仍保持对齐。未填写段位明确显示“未填写”。
- 探索在电脑上并排三张，平板与手机采用横向吸附卡列；提供上一张／下一张和当前位置，按实际滚动位置计算末尾。换组按钮位于卡列下方，换组后回到卡列起点。
- 到期时只替换失效卡位，候选足够时，其余有效卡片保持原来的位置；不再重新抽取整组。候选不足时展示实际有效数量。

## 视觉方向

按用户选择使用黑色卡底和内部黄色分区，保留米白大厅背景。参考实际薯条杯官网的黑黄配色、大字、原色英雄与细线排版：姓名用米白大字，岗位与招募人数用黄色，正文用浅色，详情箭头落在黄色方块内。宽屏三列、平板两列、手机单列；长标题自然换行，底部确认时间和详情入口对齐。

选手卡展示公开填写的常用英雄中第一个可识别英雄，作为装饰并标记“常用英雄”，不代表选手头像。英雄沿用已有资源及组件。队伍卡大数字来自实际招募人数之和，不表示评级或成绩。段位保留“段位为自述”。详情页采用黑黄身份区、米白阅读区和黑黄联系区。

配色沿用品牌变量：墨黑 `#181a17`、米白 `#eeede6`、薯条黄 `#f4c320`。大字使用官网现有字体，复制至 `public/fonts/friescup/homeground-black.woff2`（83,292 字节，SHA256 `97e8bf6a72bccc7950a2dca3bd7562c594fe9b6c26d0c69df890daba6affd9fd`）；缺字回退至现有系统字体。数字沿用 FC Data Display。没有安装新依赖。

## 浏览和探索

- 队伍招人／个人找队、浏览全部／探索三张可以切换。
- 按重装、输出、支援选择岗位，支持名字、英雄、介绍和目标的关键词搜索。
- 更多筛选包括段位原文关键词、可赛时间原文关键词、QQ 授权方式、最近确认时间；队伍额外支持正在组建／已组建。
- 可按最近确认或即将到期排序；筛选条件写入网址，详情返回和刷新后保留。列表每页六条。
- 探索从符合全部当前条件的有效需求中随机展示最多三张；同组不重复，候选足够时避开上一组。不超过三条时完整显示并禁用再换三张。
- 有效期定时更新会移除到期需求，不会自动打乱正在阅读的卡片。

读取沿用现有公开列表接口，按类型／岗位读取所有分页后再筛选与抽取。候选超过 1,000 条或读取期间总量不一致时明确报错，避免把部分数据误称为全部候选。QQ 授权及联系逻辑未改变。用户填写的段位和时间按原文匹配，不推断结构化排期或官方认证。

## 本地预览

运行 `npm run dev:lobby-preview`，访问 `http://127.0.0.1:3039/lobby?type=people&view=explore`。

预览启动实际 React 应用，使用独立内存中的虚构需求，页顶明确显示示例标签。服务仅监听本机，不读取生产环境配置，没有生产代理；所有 API 写入在本地拒绝。账号为匿名状态，不发送真实联系请求。预览关闭热更新以避免多轮迭代造成旧页面状态冲突；改动后完整刷新即可。
