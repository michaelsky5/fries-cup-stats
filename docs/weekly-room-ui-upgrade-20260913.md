## 实际页面改动

- 比赛框架：品牌与账号工具、居中对阵比分、游戏房间信息、整场地图进程依次排列。RR5 显示固定五个位置；其他赛制仍显示实际地图记录。
- 顶部两个工具控件使用同一尺寸。未知队徽显示队名占位，不把赛事标志当成队伍标志；未知比分保持 VS / 待确认。
- 字体使用项目已有的 FC Data Display 与 FCA Harmony；预览直接载入同一份字体变量，避免独立样稿的字体别名造成实际页面换行差异。
- 地图进程移到主操作前，可打开已建立地图的详情，查看类型、小分与双方禁用。平局计入完成局数，胜场不增加；详情明确区分工作记录与正式赛果。
- 两侧名单保留代表、计划首发、替补、准备与禁用，压缩重复间距。中央选图增加清晰的图片选中标记，Ban 保留英雄图像和不可选理由。
- 准备与恢复分别展示双方状态和对应人员。“本队已准备”区分等待对方与等待赛管。暂停是比赛状态，不再占用一个必经的流程步骤。
- 比赛中的协助按钮直接切换本页沟通范围。公共消息输入与发送按钮同行；私密协助继续保留独立表单与权限范围。
- 整场赛果移除重复的末图横幅与单图流程条，增加逐图比分表，分别注明工作记录或审核版本；核对、异议与结算继续使用原有服务权限及版本校验。

主实现文件：src/features/weekly-competition/RoomMatchFrame.jsx、RoomMatchFrame.module.css、WeeklyLiveRoomPage.jsx、OpeningSelectionPanel.jsx、OpeningSelectionPanel.module.css、RoomResultPanel.jsx。
