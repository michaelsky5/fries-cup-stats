# 赛事精选与完整赛程设计整理

日期：2026-09-11。范围：`design=kpr5` 的归档赛事精选、完整赛程，以及进入比赛后的轮次文案和返回路径。本批为本地实现；未提交或发布。进行中赛事主视觉和教练式逐图数据结构继续沿用已有实现。

## 页面变化

- 共用“赛事精选 / 完整赛程”两项导航，左右边界与页头、赛事状态条一致。简化上下文区域，并保留数据刷新失败说明和重试入口。
- 精选首屏以现有精选顺序中的第一场真实对阵为焦点，呈现双方队徽、系列赛比分与全部已发布单图赛果。右侧为队伍搜索、按实际阶段回看和完整赛程入口；手机优先呈现查找入口。其余精选继续保留，不给比赛套用未经数据支持的“冠军转折点”结论。
- 完整列表使用中文轮次、可独立滚动的桌面轮次索引和手机原生选择器。搜索队伍后连续显示全部匹配赛程；从队伍档案携带的精确 ID 继续优先匹配，手动输入新查询时清除旧 ID。
- 更多筛选、可逐个移除的条件、清除全部和空结果提示共用状态。清除操作保留赛事、语言和设计版本；进入比赛、切换地图再返回，保留筛选与浏览位置。
- 单图缺失分数使用 `—`，真实零分仍显示 `0`。弃权和判罚记录保留，轮空排除；日期已定但时间未定的记录不显示合成排序时间。比赛详情的阶段、轮次与入口使用同一组标签。
