# 手机首页与回顾阅读精修记录

日期：2026-09-14

## 本轮范围

延续手机阅读顺序的调整，完成归档首页后半段，以及首页进入比赛、选手、队伍与回顾后的返回体验。本轮采用现有英雄图、队徽和公开记录，保留纸色、墨色、黄色及直角控件。

- 600px 及以下增加吸顶章节选择，跳转后焦点落到章节标题。常规赛与学院赛保留六章，全高杯按现有内容保留四章，不补系列赛荣誉或回顾入口。
- 系列赛前三名改为紧凑荣誉名录；图谱保留晋级、赛程、阵容、数据四个入口，收起重复的圆形冠军中心；冠军征程改为连续比赛记录，决赛保留黄色强调。
- 人物章节压缩重复装饰，保留代表选手、职责代表和档案入口；修复 320px 时“查看档案”被旧网格挤成竖排的问题。
- 手机立即显示章节内容；桌面继续使用原有群像、图谱、征程卡与章节动效。手机保留简中、繁中、英文、韩文章节文案，韩文按赛事语义表达人物、征程与回顾。
- 首页链接保存来源及阅读位置；选手详情支持明确的“返回赛事总览”，进入竞技分析后仍保留来源；比赛与选手之间的嵌套返回继续传递首页来源。
- 回顾入口增加返回赛事总览，入口搜索、身份选择、语言切换及正文退出保留来源。返回链接校验首页路径与赛事，剔除搜索和故事章节参数；外部来源、其他页面及其他赛事不能携带阅读位置进入当前首页。
- 回顾正文在 600px 及以下将章节选择单独放到工具栏第二行，语言、复制和退出留在第一行；相应调整正文可读高度，长文仍可滚动到底。
- 修复学院赛人物回顾中残留的 `FCR / 2026`，并让同组件中的章节片头及影片预览落款采用当前赛事标记。
- 赛季菜单改用“赛程记录”单位。FCR2026 的 137 条赛程包含一条轮空 `FCR26-SWISS-R6-M15`，首页的 136 场比赛继续排除轮空；不修改数据和统计模型。

## 交付边界

本轮是归档首页与回顾阅读的本地 UI 精修，未部署、未修改真实账号或关注数据、未生成或替换赛事快照。周赛首页不在本轮修改范围；其流程验收沿用已有记录。

真实手机触摸、系统浏览器、网络、账号云同步及正式发布仍需独立验收。浏览器视口检查不能替代这些环节。原版仅作回退兼容核对，不据此确认旧版全部设计或文案。
