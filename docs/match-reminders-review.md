# 比赛提醒验收（2026-09-28）

本轮实现保存在 Stats 与 System 各自的 `codex/match-email-reminders` 分支，已在测试站完成真实收件验收；正式站尚未发布或开启提醒。

## 可体验内容

- 我的空间展示邮件提醒状态、设置入口和下一场比赛倒计时。
- 只有赛管/解说执勤关系时，也使用后端返回的周赛安排显示下一场。
- 账号设置新增“比赛提醒”：默认关闭；主动开启后可选择赛程/排班变化、赛前一小时、比赛房开放。
- 验证邮箱后可申请测试邮件；保存冲突、未保存离开、读取失败、服务未开启都有对应反馈。
- 设置与发送状态支持简中、繁中、英语、韩语。邮件正文暂为中文。
- 后端按赛事关系去重，定时运行，处理改期/取消/移除人员与重试。第一轮仅支持已公布的正式周赛。

## 两种本机预览

界面状态预览：运行 `node scripts/previewAccountReview.mjs`，打开 `http://127.0.0.3:3047/dev/account-review?page=match-reminders`。目录还提供未验证邮箱、服务未开启、读取失败、解说下一场比赛样例。这组预览使用虚构账号和内存数据，不会发邮件。

真实前后端联调：先在配套 System 工作树设置显式的本机测试 PostgreSQL 连接 `REGISTRATION_TEST_DATABASE_URL`，运行 `node scripts/rehearse-match-reminders.js`；再在 Stats 运行 `node scripts/previewMatchReminders.mjs`，打开 `http://127.0.0.4:3038/account?lang=zh#reminders`。通过 harness 打印的虚构账号登录。账号 API、数据库、定时 worker 都使用真实实现，邮件只进入本机 sink。账号 API 和公开 API 都指向本机，没有线上 API 回退。

联调结束后分别停止两个进程。System harness 会清理它自己创建的临时数据库，保留本地报告，并设有 45 分钟自动清理期限。

## 测试站与真实收件验收

- 入口：`https://hub-preview.fries-cup.com`；账号 API 固定指向 `https://test-admin.fries-cup.com`。候选构建把测试 API 地址写入 EdgeOne 产物，避免落回正式账号 API。页面保留醒目的测试环境提示；当前版本见 `/account-preview-version.json`。
- 后端候选 `34c59cc0b29156f5d93d175ef3b6735ea1205754` 使用原测试数据库的独立副本；原数据库、环境、上传文件均已备份/保留，正式容器未变。测试邮件接收白名单只包含用户明确授权的一个邮箱。
- 合成赛事 `REMINDERTEST` 和比赛均标注“【验收测试 R0928】”及“非正式赛事”。通过实际账号 API 开启后，真实 60 秒后台定时器发送了测试、赛程更新、赛前一小时、取消通知四封邮件。每封只尝试一次；重复测试请求复用同一条发送记录。
- Gmail 独立检查确认四封均在 INBOX、无 SPAM 标签，SPF/DKIM/DMARC 均通过。一小时提醒于 `04:33:55.363Z` 到期、`04:33:59.705Z` 提交邮件服务；实际 Gmail 时间为 `04:34:00Z`。这只证明该次授权邮箱验收，不代表所有收件服务商。
- 从真实邮件点击按钮后，URL 保留 `competition=REMINDERTEST&section=matches`。用户完成既有账号登录后，页面显示指定测试赛事和“已取消”的只读比赛；账号设置显示四条对应发送记录。
- 补齐了未登录入口：显式赛事比赛链接显示“登录后查看比赛安排”，在原页打开账号登录框，保留赛事与分区。公开赛事档案加载失败也不会挡住该登录入口；普通关注/公开赛程仍保持原数据检查。已检查四语言、390 宽度、登录框与 URL 保留，并通过完整 `test:account-ui` 和定向 lint。
- 验收结束恢复原先关闭的提醒偏好，测试比赛保持取消，目标账号没有等待、正在发送或失败重试的任务。既有账号密码未改变。比赛房开放与更多角色/退订场景沿用上方本机联调证据，本次没有额外发送真实邮件。

正式上线仍需成对发布、复核当前生产状态并单独启用 worker。测试站验收不等于正式发布。上线顺序及回滚资料见配套 System 文档。
