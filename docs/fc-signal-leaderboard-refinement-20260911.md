# 数据排行本地精修

## 本轮调整

- 合并排行页的赛事状态区，缩短标题区，移除独立英文眉题。桌面保持表格与选手预览并列；手机省去重复的行前说明，完整说明继续收在“如何阅读这份榜单”里。
- 将总量标为“条职责记录”，说明一位选手按职责分别记录。职责入口的数字加上“正式”标记，结果区展示当前筛选中的正式、暂定与未评级条数。“只看正式排名”移到结果标题旁，切换后总量和状态计数同步变化。正式门槛仍读取现有规则，未调整评级与排名算法。
- 名字旁使用“预览”，完整档案入口保留箭头。黑色预览把身份与总评放在一起，随后提供完整档案和加入比较按钮；常用英雄、出场样本及核心数据保留。窄屏预览加入比较后关闭弹层，焦点回到原选手名字。
- 只选一人时，“找同职责选手”会进入对应职责榜并清除姓名搜索，保留队伍等其他条件。两人起可以展开比较；满四人或职责不同的选项保留明确禁用原因。比较面板的名字可继续进入完整档案。
- 档案往返保留筛选、页码、指标视图、预览和比较选择，并保存、恢复榜单滚动位置。返回后比较栏保留已选对象，比较弹层不自动重开。
- 浅色排行区使用浅色原生控件，修正空复选框呈深色实心、容易误读为选中的问题；手机排序标签不再拆字，比较栏在窄屏下保留职责与下一步操作。
