# 比赛房深浅分区配色 · 2026-09-12

用户确认「深色框架＋暖纸色操作区」，随后指出首版棕灰底色偏离了黑黄白主题。当前保留同页深浅分区，直接复用赛事中心既有色彩变量，撤掉额外调出的棕灰、米金和偏暖分隔线；视觉接受仍以用户查看新版后的反馈为准。

## 配色分工

对照本轮读取的 `fries-cup-data-signal-design-system.md` v2.5.16：比赛环境保持深色，中央当前任务使用规范中的纸色和深色文字。

| 区域 | 用色与含义 |
| --- | --- |
| 房间框架、双方名单 | 既有墨黑 `--fc-data-ink` `#181a17`，标题及二级面 `--fc-data-ink-raised` `#22231f`，白色文字；本队标题左侧保留品牌黄识别线。 |
| 当前选禁、准备、赛果操作 | 既有纸色 `#eeede6`、标题与状态底 `#e4e3db`、输入面 `#f6f5ef`，文字 `#181a17`。 |
| 比赛沟通 | 复用同一组墨黑、深色二级面与白色分隔线，通过明度区分标题、消息与输入区。 |
| 选择和提交 | 选中项和可执行主按钮使用同一个品牌黄 `#f4c320` 与深色字；禁用项使用既有纸灰底和灰字。 |
| 状态、焦点、图片 | 浅底使用深色语义状态及深金焦点；深底使用亮色状态及金色焦点。地图缩略图保留白字与深色遮罩。 |

`RoomSurfaces.module.css` 集中定义局部纸色变量。主要操作按钮单独使用 action 色变量，避免纸色区域的深色选中文字被错误用于按钮背景。纸色只附着在中央操作区；地图、名单、沟通和全站页面不继承这组纸色变量。
