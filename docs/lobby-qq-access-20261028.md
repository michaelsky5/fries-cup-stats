# QQ 联系入口候选

对应 System `codex/lobby-open-contact-20261028`。System 迁移及 API 应先发布；本分支使用新增的卡片联系与 QQ 设置接口。

需求卡的联系栏允许已验证账号直接发起，队伍负责人身份不再作为联系门槛。联系来意可选个人组队、帮队伍找人、了解招募；不要求请求人提供 QQ。发布者通过“我的卡片 → 设置 QQ”选择逐次同意或提前开放，默认逐次同意。

查看者提交前会看到身份通知说明，发布者开放号码时保留默认不勾选的明确授权。私有联系人详情显示查看进度和双方有权访问的卡片；号码不存入浏览器持久存储，失焦、隐藏及 30 秒后清空显示，每次查看/复制重新请求服务器。QQ 打开按钮属于客户端协议尝试，保留复制号码回退，不声称已经聊天。

本地验证：构建、改动文件 ESLint、大厅/入口/QQ/密码策略 22 个测试通过（新增 QQ 测试 3 个）。用真实 API 和合成账号跑 Edge 6 组浏览器流程，包含改动前对照及 390px 外层/弹层溢出检查。真实 QQ 客户端和生产发布尚未验收。完整需求、设计及迁移说明保存在 System 的 `specs/lobby-qq-access/` 和同名开发文档。
