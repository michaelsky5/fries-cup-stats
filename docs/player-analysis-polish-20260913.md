# 选手分析 · 走势与逐图战报精修

日期：2026-09-13。

本轮承接公共 UI 检查中记录的选手分析留白问题，范围限于 FC Signal 选手分析的比赛走势组件。保留已完成的页头、职责切换、数据对照、近期赛况、英雄使用和地图索引。

## 版式

- 上区左侧呈现按真实日期排列的全场评分，右侧呈现最近在前的比赛列表。列表较长时内部滚动，不随地图数量拉高图表。
- 下区完整呈现所选比赛的阶段、日期、对手、比分、全场评分和战报入口；出场地图在其后通栏排列。
- 一至三张地图采用紧凑横行，四张及以上采用等宽地图卡。地图序号继续使用实际局序，不把只出场第二图的选手改写成第一图。
- 手机将比赛选择改为可横向滑动的紧凑列表，地图逐行阅读。点选比赛继续定位到当场详情。
- 单场出场不再占用一整张单点图：标题改为“单场比赛表现”，保留当场比分、评分与逐图入口。

## 数据与交互边界

曲线继续使用 0–10 的固定评分范围，缺失值不连线、不补零。全场评分与单图评分分别标明量纲，均直接读取既有比赛档案；赛季 OVR、排名资格和评分模型没有变更。

曲线点、比赛列表和所选比赛联动；选择保存在原有 `ptrend` 参数中。地图卡保留实际 `map` 参数，进入比赛详情后使用页面返回入口恢复选手分析上下文。

纸色、墨色、黄色、直角边界和数字字体沿用 FC Signal；未引入新素材、依赖或全局样式。
