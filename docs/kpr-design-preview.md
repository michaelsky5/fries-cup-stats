# KPR 第二轮交互样板

本轮只覆盖**已归档赛季首页**和**选手排行榜**。它是可操作的设计预览，尚未替换默认界面，也未部署或发布数据。

## 本地入口

- 冠军典藏：`http://127.0.0.1:4187/?season=FCR26&design=kpr`
- 联动排行榜：`http://127.0.0.1:4187/leaderboard?season=FCR26&design=kpr`
- 第一轮 FD 队伍页：`http://127.0.0.1:4187/teams/FCR26-T026?season=FCR26&design=fd`

顶部预览条可在 KPR 第二轮、FD 第一轮、原版之间切换。没有 `design` 参数时仍使用原版。其他页面尚未做第二轮内容重构。

## 这次尝试的设计

- 沿用薯条杯黄色 `#f4c320`、黑色和近白色；保留 FD 的字体、技术标注和英雄素材。
- 借鉴 KPR 的大字、层次和滚动叙事。首页从五人群像连续过渡到单人特写，再接阵容、冠军最后三场比赛和数据入口。
- 不劫持滚轮。可自然滚动，也可点击章节按钮；支持系统减少动态效果偏好和页面内关闭动态。
- 排行榜以紧凑表格为主，桌面右侧联动选手档案；手机点选名字打开原生模态对话框。
- 精简视图按职责展示常用指标；全部指标支持表内横向滚动、固定身份列和自定义显示列。
- 比较窗口展示两至四名同职责选手的英雄、OVR、六项公开指标及出场样本。关闭后恢复触发按钮的焦点。

## 数据边界

- 复用现有 `getArchiveHighlights`、排行榜选择器、评分、筛选、排序、分页和关注处理函数，不改变数据源或评分公式。
- FCR26 冠军为 AIP。决赛原始左右顺序是 REG 0:4 AIP；典藏以冠军视角显示 AIP 4:0 REG。
- 五人展示按本队赛季出场时间和职责选取、同一选手去重。2026-09-01 后人物图改用冠军队伍确认的展示英雄，**不是决赛首发或决赛选角声明**，也不覆盖赛季常用英雄统计。
- `ARCHIVE_OFFICIAL_HONORS` 已按组织方确认写入小狗帅哥。页面默认显示正式 FMVP 镜头，同时保留其他冠军选手的人物切换。
- 官方 FMVP 必须单独确认，并在 `src/features/kpr-design/archiveHonors.js` 填入 `season.id` 对应的 `fmvpPlayerId` 和确认来源 `source`。本赛季内部 ID 为 `FCR26`，公开编号是 `FCR2026`；当前确认值为小狗帅哥。
- 不把 DATA KING、OVR 第一或任何统计榜首自动当作官方 FMVP。特写中的数据明确标为赛季数据。
- 仍保留首次同步和缓存快照提示；开发时刷新可能先显示带提示的已缓存数据。
