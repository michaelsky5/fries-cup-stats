# 周赛公开页面检查：队标与页面语义

检查对象：FCW2026 赛事总览、赛程、周期积分、参赛阵容、队伍档案与比赛详情；同时回归原版详情及 QGCS4。

## 修复

1. **比赛详情和队伍对手误用默认队标。** System 的公开 `teams` 已包含上传队标，`matches[].team_a/team_b` 是不含队标的简版记录。统一在公开数据入口按队伍 ID 补足队标；详情选择器也覆盖独立预览的原始数据。只补队标，不复制队伍汇总分数，不按简称猜测队伍。
2. **原版详情丢弃上传队标。** 海报身份模型保留原队伍对象，原版与 Signal 详情使用同一来源。
3. **周赛展示内部阶段 `OTHER`。** 存在已发布 `cycle_week_id` 且阶段为空或 `OTHER` 时，展示模型映射为 `WEEKLY`，保留 `raw_stage`。真实季后赛、其他赛事及 System 原始 ID 不改。直接打开详情也能显示“返回周赛赛程”。
4. **图片直连间歇超时。** 复用了同域媒体代理；严格限定公开队标 WebP 路径，成功图片使用公共缓存，不转发账号凭证。原图片地址仍是回退来源，私有 API 维持不缓存。
5. **队伍档案错误等待试运行排名。** 周赛档案读取已发布周期排名；不计积分的周期显示“不计积分”，缺少排名时保持待公布，不使用瑞士轮计算名次，并保留公开并列排名。
