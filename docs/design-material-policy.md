# 数据站设计素材使用记录

更新时间：2026-08-31。本文记录本轮设计约束和待核对事项，不是对现有网站的法律合规结论。

## 用户已确认的使用背景

- 目前没有赞助展示、广告或收费。
- 没有单独取得暴雪、网易或素材作者的素材授权。
- 本轮复用的 FD 英雄素材由用户本人在《守望先锋》游戏内截图取得；来源依据是用户在 2026-08-31 本次对话中的明确说明。
- 仅在允许范围内使用素材；保留薯条杯黄黑白、FD 视觉语言与 KPR 交互方向。

没有单独授权不代表没有适用的公开许可；网站免费也不等于任何图片、视频或改图用途均获许可。必须按具体素材及使用方式核对。

## 本轮选材处理

| 选材板条目 | 当前处理 |
| --- | --- |
| 01 原画作者作品、08 电竞工作室案例 | 仅供内部设计参考；未确认复用授权，不直接作为正式网页素材 |
| 02、03、04 官方媒体包，05、06 官网角色 PNG，07 官网底纹 | 待核对公开许可对来源、展示、修改和再分发的覆盖范围；不因无广告或官网可下载而自动通过 |
| 09 官网 F2P 宣传片 | 仅作参考，不根据社区视频政策推定可剪辑或用作本站背景视频 |
| 官网职业与技能图标 | 按具体官方来源核对使用条件，不与用户自行截取的游戏画面混为一类 |
| FD 已有英雄素材 | 用户已确认来自本人游戏内截图；按自行游戏截图用于粉丝网站展示的场景评估，不再标为来源不明的网络图片 |
| 自行制作的版式、图形、动效及原创品牌舞台 | 作为下一轮视觉实现的优先基础，不复制第三方具体美术作品 |
| CC0 材质、开源图标与字体 | 核对具体文件和许可证，保留所需通知；素材库的许可不自动覆盖网站示例渲染、文案或品牌标识 |

如需要守望先锋动态画面，可优先评估有权使用的自行录制游戏画面，按暴雪社区视频政策制作免费展示的视频。该政策不涵盖未纳入游戏的宣传片或广告；录像中的第三方音乐、作者作品等权利仍须单独处理。

## FD 英雄截图的来源澄清

- 用户自行截图的来源已经明确，不再要求这些图片具有“官方透明 PNG 下载链接”，也不把它们等同于原画作者或工作室的作品集图片。
- 暴雪 Legal FAQ 明确讨论自行游戏截图能否放在网页上，并给予附条件的肯定答复；应使用该条款评估本次展示，而不是从 FD 的软件开源协议或社区视频政策推导图片许可。
- 自行截图不转让其中游戏美术的版权。FAQ 要求保留版权等通知，并限制修改内容；已有抠图、网页转码及呈现方式不能仅凭来源澄清就记录为全部获得许可。
- 保留英雄群像与人物特写的设计方向，不以“没有单独授权”或已澄清的来源问题自动撤换为奖杯。第三版奖杯仅为可对照的设计样板，不是英雄图被确认禁止使用的结果。

## 实施边界

- 对每项拟上线素材记录来源、许可依据、用途、修改方式及归属说明；未确认的条目留在参考区。
- 不以抠图、滤镜、去水印、外链加载或 AI 重绘代替权限核对。
- 不把待核对素材上传生产或整理为面向公众的素材下载包。
- 不批量删除、撤换现有素材，也不把“尚未确认”写成“违法”。既有使用状态与新素材上线判断分开处理。
- 使用背景若变为有赞助、广告、收费或素材再分发，重新评估适用条件。
- 正式 FMVP 必须由组织方确认，不由统计榜首推定；FCR2026 已于 2026-09-01 确认为小狗帅哥。
