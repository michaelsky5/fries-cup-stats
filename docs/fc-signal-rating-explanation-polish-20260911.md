# 职责导航与评分依据精修 · 2026-09-11

状态：本地实现与验证完成，未提交、推送或发布。评分沿用 v1.4；本轮只调整呈现、文案与阅读顺序。

## 实现

- 职责导航填满控制区，桌面四等分，700px 以下两行两列，最窄屏保持完整单行职责标签与 52px 高度。数量写作“条正式排名”，继续显示全季正式职责记录；搜索和队伍筛选不改变这一口径。
- Signal 评分弹层首先展示身份、评分状态、最终 OVR 和主要原始分贡献。原 OVR、实际对手修正、最终 OVR 沿用已有结果字段，明确显示当前样本上限。
- 正式样本默认收起门槛；暂定样本默认展开正式门槛缺口；未评级展示暂定门槛，不展示数值评分或贡献图。未评级的折叠入口只承诺比较基准与版本，不承诺不存在的计算过程。
- 贡献图继续展示全部指标与权重，补充正负方向与中性中线，明确“原始分贡献并非 OVR 直接加减分”。主要贡献摘要不改变原始指标次序。
- 完整计算、对手历史及基线信息放入原生 details。评分弹层的 Portal 根节点设置 Signal 设计属性，原版维持原有布局和完整展开内容。
