# 选手档案收尾精修记录

日期：2026-09-14

范围：选手档案与个人分享。沿用既有档案、征程、竞技分析框架以及 FC Signal 的纸色、墨色、黄色和直角控件；未发布。

## 页面与交互

- 仅一场出场的选手保留一份完整代表比赛，移除重复的赛季片段及其章节入口。按钮明确写为「查看出场记录」，不使用赛季最佳称号。
- 没有公开出场记录时，封面显示本届阵容成员、登记职责、队伍与说明；主入口前往所属队伍。移除三项零值、重复等待区和页底的空记录入口，保留顶部三页导航与身份分享。
- 手机封面先呈现队伍和赛季，姓名与紧凑英雄图并排，荣誉、出场规模、英雄选择与操作随后。英雄选择仍来自实际记录；无记录时使用队徽。
- 手机的代表比赛先显示对手、比分、评分、范围说明与本场英雄，逐图记录按需展开。桌面继续完整展示，切换职责后使用该职责对应的地图。
- 档案分享继承当前封面英雄及其职责。赛季卡面也可主动切换实际出场英雄；最多、并列最多及主动选择分别表达，出场总数和 OVR 不随图像变化。比赛分享始终使用该场真实出场英雄。
- 分享预览增加「放大查看 / 返回分享设置」。大图区域内部滚动，起点为左上角；Esc 先返回设置，再关闭弹窗，焦点返回发起操作。可用主题、关闭按钮和选择框采用清晰墨色文字。
- 收齐档案英雄图数与分享卡的英文单复数。生成图片后提示「分享图已生成」，避免把文件生成等同于浏览器保存完成。
