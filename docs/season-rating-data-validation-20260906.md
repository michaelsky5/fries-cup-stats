# 用现有数据验证赛季评分

2026-09-06，本地离线分析。输入为 FCR26 公开快照，SHA-256：`a22f3f4c44c56e9349adfd7cf1bf93a1e7770a69913a02b5ef810673f485f08a`。

可以基于现有数据建立可重复的验证流程，不需要先新增录像标注。这轮验证衡量历史评分对后续统计表现的延续性，以及对正常比赛胜负的辅助判断能力。它不能直接证明个人技术排名正确。

## 方法和范围

将每个比赛日整体作为待验证数据，只使用此前日期的比赛计算英雄基线、个人历史评分、样本资格和队伍信息。瑞士轮结束时的冻结基线明确关闭，避免它包含待验证日期之后的记录。当前队伍名单、赛季汇总和最终排名也不用于重建历史特征。

评分权重保持当前配置，不做参数搜索。现有人工规则曾参考本赛季数据，因此这属于固定规则的回溯性时间验证，不是完全未接触过的新赛季盲测。方法参考 [Forecasting: Principles and Practice 的时间序列交叉验证](https://otexts.com/fpp3/tscv.html)。

可用数据为 113 场正常比赛、2,840 条英雄记录，其中 111 场有有效玩家记录。排除 10 条来自非正常赛果的记录。

- 个人表现：预测时已达到正式样本门槛，待验证比赛中该职责至少出场 10 分钟。共 474 个选手 × 职责 × 比赛样本，覆盖 140 个选手职责、60 场比赛、18 个比赛日。
- 胜负：两队都能从此前数据选出 1 重装、2 输出、2 支援，以历史出场时长选人；不使用待验证比赛的真实首发名单。共同样本为 63 场、19 个比赛日。预测同分计半个正确，实际平局排除。
- 日期之间逐步前进；先前待验证日期在下一日期成为历史数据。同一天的英雄片段与比赛始终整体留出。

## 首轮发现

| 个人后续表现的预测方法 | 平均绝对误差，越低越好 |
| --- | ---: |
| 固定预测 50 分 | 11.262 |
| 同职责历史均值 | 11.268 |
| 当前样本收敛分 | 11.831 |
| 个人历史原始均分 | 12.181 |
| 最近三场均分 | 12.387 |
| 上一场表现 | 14.891 |

个人误差以未来比赛的原始数据表现分为目标；每场先平均选手误差，再对各场等权。该目标仍由当前指标体系定义，验证的是其持续性，不是独立标注的技术能力。

1. 样本收敛有帮助。原始均分相对当前收敛分的误差增加约 0.350，按比赛日重抽样的探索性区间为 `[0.115, 0.594]`。不过当前收敛分仍没有优于固定 50 分这个简单基准，其差异也不足以作确定判断。
2. 强调近期表现暂未获支持。上一场与最近三场的预测误差都更大。不能仅因近期高光就推断该选手后续会维持相同水平。
3. 个人排序的延续性偏弱。31 个满足样本门槛的日期 × 职责组中，v1.4 OVR 对后续表现的 Spearman 相关中位数约 0.124，分组平均约 0.131；v1.3 基本相同。
4. 胜负样本中，v1.3 与 v1.4 都是 39 / 63，即 61.9%。队伍 Elo 为 36 场明确正确、5 场预测同分，半计后 61.1%。当前没有证据说明 OVR 优于队伍 Elo，也没有观察到这批样本中对手校正提高了胜负判断。

误差较低和个体区分度是两个要求；恒定预测可以降低误差，却不能区分选手。后续模型不能仅靠让所有分数更接近平均值来宣称进步。

## 据此建议的下一步

优先研究各职责的实际波动与评分不确定性，比较不同收敛策略能否同时降低后续误差、保留排序区分度。将近期三场和上一场作为对照，暂不据这次数据提高近期比赛权重。对手校正继续保留为有边界的赛程说明，其参数是否有效需要新增比赛进一步验证。

可以把这些检验作为后续每个候选版本的固定对照：共同样本的误差、日期内职责排序、胜负表现、覆盖范围和新旧排名变化。先比较，再决定是否改变网页评分。

## 工具与验证

运行：

```powershell
node scripts/validateSeasonRatings.mjs
node --test scripts/assertSeasonRatingValidation.mjs
```

可选参数：`--input <公开数据 JSON> --output <报告目录> --season FCR26`。

输出：`artifacts/season-rating-validation-20260906/report.md` 和 `report.json`。JSON 保存每个日期的训练范围、排除计数、逐条预测及目标、模型文件哈希和探索性区间。

9 项测试覆盖：日期边界、关闭未来冻结基线、未来指标／最终排名／当前队伍信息不改变历史预测、英雄片段聚合、无需待验证首发名单、异常记录排除、与网页评分适配器的目标一致性、排序相关与按日重抽样、空样本处理。定向语法与 ESLint 检查通过。应用代码、公共数据和评分参数未改动，本次没有发布线上版本。

这些结论仅针对本轮共同样本。只纳入继续参赛且已有足够记录的选手，跨日重复玩家和同队数据存在依赖；按比赛日计算的区间属于探索性结果。比赛胜负属于团队结果，应与个人数据验证分开解读。
