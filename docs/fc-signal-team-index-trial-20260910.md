# 队伍目录 · 队旗展墙本地试版

后续决定：此版队旗网格与整排展开已由选手页基准的共同框架替代；真实队徽、完整阵容和赛程继续保留，详见[三目录统一记录](fc-signal-roster-family-trial-20260910.md)。以下保留当时试作事实。

日期：2026-09-10。范围：`/teams?design=kpr5`。接续选手目录与职员署名册的本地试版，尚未提交或发布。

## 设计落点

- 「一支队伍，一起上场」：从真实队徽、队名与共同报名的名字进入一支队伍。纸色、墨色、薯条黄和粗体标题延续 FC Signal。
- 目录采用队旗展墙。宽屏四列、中等宽度三列、手机两列，形成可以连续浏览的队伍展示；搜索、名单筛选、排序及分页仍可直接使用。
- 点击队旗，在这一排末尾展开完整横幅。左侧墨色队伍身份页呈现队名、队徽、名次、经理、教练与展馆入口；右侧纸色名册呈现全部已登记选手和分阶段赛程入口。
- 首次进入不默认展开某一支队伍。缺专属队徽时用真实简称排版，不将通用 OW 标志当作队伍标志。队徽保留自身颜色。
- 手机保持两列浏览，横幅单列展开；收起后焦点回到对应队旗。减少动效设置下取消展开动画及平滑滚动。
- 队伍展馆、赛季征程、选手档案使用已有返回状态。页码、筛选与选择通过 URL 保存；关注排序让所选队伍跨页移动时，同步定位到所在页。

## 数据边界

- 报名阵容与职员复用现有 roster selectors；显示全部登记成员，不推断首发，不用英雄图代替队伍身份。
- 阶段数量表示已发布赛程记录，包含待赛、轮空及判罚，不等同于实际交手数或胜场数。阶段入口复用现有征程筛选 URL。
- 名次复用 `getTeamSeasonPresentation`，缺少已发布依据时保持待生成或未发布。
- 比赛归属优先使用发布的队伍 ID，防止同名队伍相互借用记录；缺 ID 的历史记录保留名称与路由兼容。
- FCR2026 AIP：6 位报名选手，瑞士轮 6 条、季后赛 6 条赛程，最终冠军。浏览器与本地公开快照一致。
- QGCS4：独立的 19 支队伍；WHG X SPC 展示 7 位报名选手、两位教练、5 条赛程（小组赛 4、季后赛 1）。
