# 第一批：公共页头与参赛阵容目录

日期：2026-09-09。状态：本地实现与浏览器检查完成，供视觉审阅；未提交、推送或部署。

依据：[薯条杯设计系统](fries-cup-design-system.md)与[赛事中心实施规范](fries-cup-data-signal-design-system.md)。

入口：[阵容总览](http://127.0.0.1:3026/roster?design=kpr5&lang=zh&season=FCR2026)。

## 当前呈现

- 公共新版页头的中文产品标识改为“赛事中心”，统一中文首页标题和导航辅助名称。英文仍沿用已有 `DATA CENTER`，没有另行确定新的英文品牌；本批不代表官网及所有独立资产已完成更名。
- 新版公共页面在已有记录可读时，统一使用紧凑同步提示，保留来源状态与重试入口。首次加载和完全无数据的错误仍采用完整状态区。
- 阵容总览保留一个墨黑主视觉，用纸色、队徽和英雄群像区分战队、选手、职员三个入口；移除自述设计方法的文案与过长的舞台。
- 三个目录统一为紧凑导航、标题与范围、筛选、实际名单。桌面使用左侧名单与右侧对象预览，手机优先展示名单，主动选择后在对应条目下展开简介。每个条目同时提供直接进入档案的链接。
- 目录选中项使用 `rosterFocus` 写入 URL，与已有搜索、职责、排序和分页共同恢复。换筛选或分页会清除失效选择；切换赛事沿用现有的上下文清理规则。
- 队伍与选手链接携带目录返回来源和阅读位置；保留现有展馆、征程、分析及选手档案内容。职员可进入所属队伍档案或已存在的赛事署名回顾。
- 无英雄出场记录时使用明确的 FC 身份占位与缺数据文字，不再借用无关英雄。职员总量明确称为档案条数，避免将跨队伍、跨职务记录说成去重人数。
- 新增目录和控件文案提供明确的中英文呈现；玩家昵称与 BattleTag 保持原值。原版页面继续使用原目录布局。

## 边界

浏览器使用现有公开快照，期间上游刷新仍返回失败或更新中，页面保留可读记录。本批没有修复上游更新，也未验证真实账号、数据库写入或线上发布。

本轮重排四个阵容入口与公共呈现，保留现有目录数据选择器、评分、关注容量与档案内容。进行中赛事总览和赛程重排仍属于后续批次。
