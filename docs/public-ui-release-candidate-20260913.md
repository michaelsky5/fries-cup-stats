## 本轮变化

- 无设计参数的普通网址默认采用 FC Signal（实现兼容值仍为 `kpr5`）。空参数和未知设计值采用相同默认值。
- `design=kpr5`、`design=original` 及已有设计版本链接继续有效。导航、赛事切换与回顾入口保留语言和赛事，普通导航不再自动附加设计参数。
- 设计工具条只在开发环境、主动指定 `designPreview=1` 时出现。生产构建忽略该开关，不展示工具条。
- 工具条隐藏时同步调整吸顶位置。根容器建立独立格式化上下文，避免首个导航栏的外边距穿出纸色背景。
- 无设计参数的职员页面标题按战队职员、赛事职员分组；旧版链接保留既有标题。
- 评分、赛事数据模型、周赛开发开关和账户权限均沿用已有实现。

## 数据请求与发布边界

公开快照初次读取成功；检查中一次后台刷新失败，页面继续显示已有记录，点击重试后恢复为“数据更新于”。同时，一次独立的完整快照请求触发 25 秒超时。这个结果说明失败与恢复界面可用，也说明本轮不能声称网络已经稳定或可以直接切换正式站。

正式发布前仍需完成：

1. 在目标托管环境核对静态资源、公开 API 代理、缓存与完整快照传输，复核慢网及失败恢复。
2. 确认账户相关改动是否随这版发布，并完成相应真实账户验收；不要直接从仍混有其他任务改动的工作区整体发布。
3. 若开放正式周赛，接入真实已发布周期快照。当前 DEV 专用周赛样例继续保持开发限定。
4. 固定批准的发布内容和生产环境变量，保留当前线上部署标识及原产物，再执行正式切换。

## 回退

`VITE_DEFAULT_PUBLIC_DESIGN=original` 在构建时生效，用于把普通地址切回旧版视觉，显式设计链接仍优先。已经构建的站点不能仅通过修改运行时环境变量完成切换。

`visual-fallback/` 已实测可用，但它仍包含当前前端逻辑，不能代替上一线上版本的完整回退包。完整回退应恢复原部署及相应代理、环境配置；本轮没有修改后端或数据库。

本轮修改前的相关文件备份保存在 `tmp/public-ui-release-20260913/before/`，仅供核对本轮差异。后续若出现并行改动，应按差异恢复，不应整目录覆盖。
