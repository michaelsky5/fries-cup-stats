## 本轮变化

首屏从五张英雄半身图的拼贴改为队名、决赛赛果和原创奖杯概念。奖杯以五根黄黑金属切片呼应薯条，不是赛事现有实物或官方奖杯的照片。图形参考 FD 的黄黑白与标记语言，保持 KPR 方向的空间感、滚动叙事和克制的交互。

原生滚动在冠军舞台与选手档案之间过渡。桌面指针只提供小幅分层视差；这是图片与 CSS 的空间效果，不是可任意旋转的 WebGL 模型。不劫持滚轮。章节按钮可以直接切换，动态开关与系统减少动态偏好均会关闭视差和滚动补间。

人物区以选手名字与可切换的立体数据卡展示真实档案。选手、职责、OVR、职责核心指标和链接一同切换。手机使用独立上下构图；原有第二版的英雄人物构图仍可对照，没有删除英雄素材。

下方连接赛季代表选手、冠军最后三场已完成比赛、队伍档案、比赛详情和原有排行榜。排行榜的评分、排序、筛选与比较逻辑没有改动。

## 数据边界

- FCR26 冠军是 AIP；原始决赛顺序是 REG 0:4 AIP，新舞台按冠军视角显示 AIP 4:0 REG。
- 五位代表选手按各职责的赛季出场时间选取，不是总决赛首发名单；人物图使用冠军队伍确认的展示英雄，不是决赛选角，也不覆盖赛季统计。
- FMVP 继续使用 `archiveHonors.js` 的组织方确认配置。2026-09-01 已确认小狗帅哥，默认显示正式 FMVP 镜头；没有以榜单第一代替官方获奖人，其他冠军选手仍可切换查看。
- 数据卡的 OVR 为赛季评分，另列的职责指标才是每 10 分钟；没有把评分也标为每 10 分钟。
- 保留现有加载、同步提示和缓存，不伪造同步完成。

## 素材记录

沿用 [素材使用记录](./design-material-policy.md) 的边界。首屏没有新增暴雪、网易、原画作者或工作室的图片和视频。

新增主图由内置 `image_gen` 生成，未输入第三方参考图，描述为原创的五根黄黑金属切片奖杯。页面明确标记为概念图。AI 生成不等于取得独占版权，也不改变既有字体、队徽或其他游戏素材的权利状态。

## 验证与恢复

新组件按需加载，只在 `design=kpr3` 的归档首页使用。没有添加 npm 依赖、改动评分算法或写入赛事数据。

本轮修改前的集成文件副本保存在 `artifacts/kpr-design-round3-20260831/baseline/`，用于对照这轮改动，不应覆盖用户随后产生的新改动。截图、原始比赛与指标核对、浏览器检查记录也在同一目录。

构建使用 `node node_modules/vite/bin/vite.js build --outDir artifacts/kpr-design-round3-20260831/build --emptyOutDir`，没有运行会更新其他生成文件的项目 `prebuild`。正式上线、素材清理、提交与推送均未执行。
