## 已完成的功能与适配工作

| 用户路线 | 现在的行为 |
| --- | --- |
| 打开比赛详情 | 比分、双方队伍与 FT/BO 赛制集中呈现；980px 和手机保持双方对比分的对应关系。比赛房、返回和复制链接集中在顶部工具栏。 |
| 查看单图与返回 | 手机地图入口在自身容器横向滚动；选图更新可分享的 URL，展开对应地图并定位。来自队伍负场筛选的访问，返回后保留队伍页签、筛选和阅读区域。直接访问比赛时，返回有确定的赛程目标。 |
| 查看不完整记录 | 已发布比分但缺少选手统计的地图仍保留，明确提示缺失。待赛地图不把占位比分当作赛果；弃权场次不生成虚构地图或选手统计。 |
| 找录像和比赛人员 | 人员与录像收进可展开资料区；有明确单场录像地址才标“本场录像”，赛事账户空间标“赛事录像库”。同一人员的姓名与 BattleTag 别名合并，不合并不同账号。 |
| 查看归档队伍 | 使用最终名次、冠军、最后一战和完成场次。最终排名尚未发布时保留未知，不把不完整排名列表的首队推成冠军。进行中赛事继续使用当前排名、晋级和加赛状态。 |
| 查看阵容和队伍数据 | 核心卡片改称“出场核心”，职责沿用选手名单中的职责，避免补位卡片被预设槽位误标。提高队伍和比赛详情辅助文字字号；手机详情省去重复阵容子导航。 |
| 队伍到完整赛程 | 入口显式进入列表，并用队伍 ID 精确匹配。NF 仅返回自身 7 场，不混入 NFA 的 4 场；手动修改搜索后恢复普通检索，重置回到全部 44 场。 |
| 生成队伍分享图 | 页面和图片共用最终/当前名次语义。手机能看到完整卡面，英雄调整区域独立滚动；支持焦点循环、Escape 关闭、关闭后还原焦点和页面滚动。实际导出 FCR26 AIP 与 QGCS4 NF 两张 PNG 并打开检查。 |

本批详情样式通过 `data-design="kpr"` 限定，主要叠加在已有组件结构上；保留 `design=kpr5` 预览兼容和原版布局。数据真实性、导航和分享行为的修正由两个设计共同使用。上述实现和下列检查证明相应功能及适配行为，不代表整页已达到 FC Signal 的视觉标准。
