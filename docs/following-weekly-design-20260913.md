# 我的关注 · 周赛适配与视觉精修

日期：2026-09-13。FC Signal 2.5.21。本轮是本地实现与设计预览，未发布。

## 设计

保留「近况与关注对象」「全部关联比赛」两条路径，顶部改为与赛事中心一致的等分导航、左对齐文字和整格黄色选中线。周期选择复用周赛总览、赛程与晋级形势的控件。

近况以墨色主对阵呈现状态、当前比分和 RR5 五局位置，旁边分别呈现后续对阵与最近赛果。五局轨道只为已有地图记录提供详情链接，未公布的地图保持待公布；详情链接带地图参数，避免页面挂载后仅有锚点却未定位。

关注队伍卡片呈现已公布周期积分、名次、并列和已赛数，并直接进入该队的周期历程。只关注一种对象时，卡片使用整行空间，另一类保留紧凑入口。选手在发现列表、对象卡片、管理窗口和已选列表共用常用英雄头像，数据缺失或图片失败时显示姓名缩写。沿用现有英雄素材，无新增人像或随机英雄。

关注管理保留搜索、筛选、草稿、保存、取消、排序和备份行为。标签页使用黄色底线与直角控件；手机保持可滚动目录和可见的保存区域。列表筛选继续在原控制区显示结果与清除操作，不另加一行筛选标签。

## 数据与交互约束

- 周赛仅纳入所选公开周期、已发布周次中引用的比赛；不混入试运行或未发布对阵。无受支持的公开快照时保持空状态，不回退到瑞士轮。
- RR5 的 3:0 仍服从公开的进行中状态，不宣布完赛或换算周期积分。待审核比分带明确说明；延期、取消、裁决和未知状态保留独立含义。
- 积分、名次、并列与已赛数均来自公布榜单。缺失不是零，试运行显示不计积分，不生成排名。
- 关注名单仍按赛季保存。切换周期重置状态筛选与分页，保留关注对象；查看记录按赛季、账号和周期隔离，不把切换周期当作新增动态。
- 选手赛果仅由正式出场记录关联；未完赛的所属队伍赛程不表示选手已出场。
- 比赛链接保留周期、周次；详情返回保持我的关注来源与筛选。地图链接使用 `map` 参数和锚点。

## 验证

模型检查包括新增 10 项周赛关注测试、既有关注与管理检查，以及周赛总览、赛程、晋级和详情进程回归。第一次联合运行共 62 项 Node 测试通过（其中总览脚本另含 18 条检查）。最终变动后再跑关注相关检查、ESLint 与独立目录构建。测试和构建输出保存在 `tmp/following-weekly-20260913`。

真实浏览器检查包括中文与英文、桌面与 390px 手机、关注即时反馈、按队伍过滤、周期与试运行切换、地图详情定位与返回、管理窗口取消草稿和保存，以及 FCR2026 的真实英雄记录与无记录缩写。审核与延期使用独立只读样例服务复核。当前完整验证结论见同目录 `verification.md`。
