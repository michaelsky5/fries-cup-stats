## 本轮范围与构图

只调整新版选手目录。新增 `src/features/player-index/`，页面数据、查询参数、分页和关注逻辑继续由 `PlayersPage.jsx` 与原选择器提供；战队、职员、门户和详情页未在本轮重排。

- 桌面约四成名单、六成人物。搜索、职责、排序和更多筛选收进左侧索引，右侧呈现完整人物版面。
- 大姓名和 BattleTag 建立身份；队徽与队名连接真实队伍档案；已记录英雄构成人物画面，地图与分钟保留在底部的记录区。
- 有职责筛选时明确标注统计范围。没有英雄记录时使用队伍身份图形与缺数据文字，不借用无关英雄或编造出场数据。
- 手机先显示名单，主动选中后在条目下展开人物版面；切换对象有短暂过渡，并提供减少动态效果的 CSS 分支。
- 新人物容器使用明确尺寸和限定作用域的定位规则，修复上一稿中英雄素材已加载但显示尺寸为零的问题。
