# 三目录首屏与素材细化

日期：2026-09-11。状态：本地实现、响应式检查和构建完成，供视觉审阅；未提交、推送或部署。

## 本轮范围

延续 2026-09-10 的共同框架：以选手目录为基准，三个目录共享查找方式与阅读顺序。用户确认主要使用现有英雄图、队徽和头像，本轮实施首屏密度与三种素材构图的细化。

- 共用标题减少重复的赛事代码；状态提示、目录栏头、分类与搜索之间的间距收紧，排序标签和选项同行。常规名单行高和姓名字号保持原尺度。
- 桌面面板随视口高度调整：常规 620–740px，窄桌面 640–740px；英文长内容或完整阵容可自然增长。
- 选手保留英雄主视觉，调整图像顶部空间、长姓名避让和底部可读性。无出场数据时集中说明名单收录状态，大幅队徽明确标注所属队伍。
- 队伍把已发布赛季结论移到队名旁；队徽使用纸色安全区并保持原比例。经理、教练为辅助身份，完整报名阵容保持清楚可读。
- 职员突出姓名、职责和头像，统计数字缩小。队伍职员优先使用已登记的公开头像，其后为真实队徽；无图回退为姓名排版。`getStaffAvatar` 的新增可选参数仅让该场景避免尝试未登记头像，既有调用的默认行为保持原样。
- 外层间距规则限定于 `design=kpr5` 下的 `/players`、`/teams`、`/staff`，不覆盖阵容总览、详情或原版分支。

关联比赛入口扩展和手机精简展开模式留待后续设计；本轮沿用已有档案、阵容、征程和回顾入口。
