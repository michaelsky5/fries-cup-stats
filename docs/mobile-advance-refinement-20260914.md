# 手机晋级形势精修记录

日期：2026-09-14。范围：赛事中心 FC Signal 晋级形势及周赛晋级页面。仅本地修改，未部署或发布。

## 阅读顺序

- 手机用紧凑的「晋级形势」页头交代用途，直接进入阶段与选队；桌面保留路线封面。
- 瑞士轮在选队后先显示队伍身份、实际战绩、去向与逐轮比赛。完整排名继续保留，手机随页面自然滚动；各轮战绩分布按需展开。去向筛选仍使用已公布的区域。
- 常规赛季后赛把选队入口前置，将同一条真实路线改为手机纵向记录，比分说明以所选队伍在前。胜者组失利、转入败者组、止步、夺冠与亚军分别表达；完整双败图可展开查看。
- 学院赛季后赛和突围赛、全高杯季后赛使用各自已发布轮次和对阵，增加手机单队路径。全高杯季军赛保留在相关队伍的路径中，学院赛不套用常规赛四分区。
- 全高杯手机小组赛按小组切换；实际 D 组四队，其他三组各五队。桌面继续并列展示所有小组。
- 手机最终结果先呈现冠军身份、总决赛比分和路径规模，再看逐场记录与最终排名。桌面路径和冠军档案维持并排。
- 周赛收拢标题及阶段说明，保留周期选择、积分榜和队伍记录，并增加返回积分榜选队的入口。试运行改用「返回队伍列表」。

## 状态与数据边界

队伍、去向、突围分区、小组和签表展开状态分别使用 `teamId`、`zone`、`division`、`group`、`bracket` / `lcqBracket` 保存。状态更新保留赛事、语言、阶段及已有参数；跨赛事失效的队伍选择仅回退到本赛事真实参赛队伍。比赛和档案链接保存来源，返回恢复选择及原阅读位置。

适配器的赛果同时支持已公布的 `winner` 与 `winnerId`，只在已结束状态读取，不根据比分推断胜者。此轮修正了通用双败图误写成单败的说明。周赛不从实时比分增加周期积分；试运行不生成正式排名。没有公开对阵或赛果时保留待公布说明。
