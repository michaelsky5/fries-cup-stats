## 额外发现并修复：System 周次数据读取错误

`/me/weekly-competition` 返回的 `rules` 和 `continuity` 位于 `entries[].weeks[]`，与 `participation` 同级。页面原先读取 `participation.continuity` 并只使用周期规则，导致继承人数可能显示为 0，周次覆盖规则也未参与前端核对。

现在按真实接口结构读取，并优先使用周次规则：

- 首次参赛显示“首次参赛”，不显示“保留 0 人”。
- 已有参赛历史显示最近一次参赛成员标记，不再混用“周期核心”或“上周名单”。
- 实际仅保留 2 人时前端阻止提交，保留 3 人可以继续。
- 历史正式名单缺失时显示明确原因并阻止提交，由赛管核对。
- 固定核心的旧规则模式继续保留对应标记和校验。
