# 手机英雄与地图数据精修记录

日期：2026-09-14。范围：FC Signal 英雄索引、英雄档案、地图索引、地图档案。仅本地修改，未部署或发布。

## 阅读顺序

- 600px 及以下重新组织内容。英雄索引保留职责、查找、排序，将三个职责代表收成一排紧凑头像列；完整英雄名单继续纵向浏览。
- 英雄档案收拢封面，保留英雄辨识度和记录出场率。使用选手、出场地图、可回溯地图记录作为三个直接入口，随后进入选手列表。重复的封面计数和章节装饰省去视觉占位，统计解释保留在口径说明中，章节标题仍可供辅助技术读取。
- 地图索引将长口径说明收进原有说明区域，在列表标题旁保留入口；记录数、平均时长及赛季占比仍有各自列名。
- 地图档案将名称、规模和地图图像并排；赛季占比、平均时长及其有效样本、队伍规模在下方三列呈现。同模式占比可以展开比较查看。
- 地图英雄的全部职责视图先列各职责的首位英雄、出场率及样本；点选职责或“查看全部”浏览完整名单。并列标识、队伍单图分母和相关比赛入口保留。
- 单图纪录在手机按需展开，保留真实总量、人物及具体比赛入口；默认先进入可筛选的比赛记录。
- 桌面保留完整英雄展示卡、英雄选手与地图并排分析、完整地图图像和展开的同模式比较。

## 阅读状态与数据口径

英雄档案用 `heroPlayers`、`heroMaps`、`heroRecordLimit` 保留展开状态及已加载记录数量。筛选改变时重置记录页数；切换英雄或返回索引时清除详情专用参数。索引进入英雄档案保存来源及滚动位置，返回仍保留搜索、职责、排序和当前语言。

地图的 `mapContext`、`mapExtremes` 保留手机展开状态，原有职责、阵容、队伍及比赛筛选参数继续使用。英雄、选手、地图和比赛之间沿用原有来源与返回位置。修正地图与英雄返回链接在语言切换后带回旧语言的问题。

没有改变出场、镜像、行政裁决、时长、阵容、胜率或 v1.4 评分计算。记录出场率仍以有可识别英雄的队伍单图样本为分母；镜像计两次出场、一条地图记录。手机隐藏的是重复信息，未生成缺失统计或从英雄图推断阵容。英文修正单个使用选手及单次出场的复数文案。
