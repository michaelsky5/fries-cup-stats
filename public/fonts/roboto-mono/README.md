# Boarding-pass numeric font

- Family: Roboto Mono, variable upright weight 100–700.
- Source: https://github.com/google/fonts/tree/main/ofl/robotomono
- Original file: `RobotoMono[wght].ttf`, saved here as `RobotoMono-Variable.ttf` without modifying its contents.
- Downloaded: 2026-08-31.
- License: SIL Open Font License 1.1; the original notice is included in `OFL.txt`.
- Use: locally hosted dates, statistics and archive IDs in FCR26 player boarding passes. It is registered under the CSS alias `FCR Boarding Mono` only when that format is generated.
